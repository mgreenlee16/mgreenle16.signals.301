These are the official Chapter 4 learning objectives, word for word. Tick each item when you can do it without notes. The ticks are saved in this browser.

Definition and properties of the Laplace transform (Lesson 5)

  • Calculate the Laplace Transform for a given function and specify the corresponding domain.
  • Use the following properties for understanding and simplifying Laplace transforms: linearity, scaling by exponential function, convolution, differentiation, integral, time shifting.
  • Understand and use the definition of convolution and its physical meanings.
  • Use the various properties of delta Dirac function.

Inverse Laplace transform (Lesson 6)

  • Carry out partial fraction expansion for proper rational functions.
  • Do Inverse Laplace Transform using the partial fraction expansion.
  • Identify zeros and poles for a given rational function.
  • Specify the type of time-domain functions for poles or pairs of poles.

Transfer functions (Lesson 7)

  • Understand the definition of linear and time invariant (LTI) systems.
  • Calculate the transfer function from the impulse response.
  • Calculate the transfer function from given differential equation characterizing the LTI system.
  • Calculate the input or output or the transfer functions for LTI systems.

Solving differential equations (Lesson 6)

  • Carry out Laplace Transform for differential equations.
  • Solving differential equations in the Laplace domain (s-domain) and transform the solution back to the time domain.
  • Identify and incorporate initial conditions of differential equations.

Applications of the Laplace transform (Lesson 7)

  • Analyze RLC electric circuits and identify the transfer functions.
  • Analyze mass-spring-damper mechanical systems and identify the transfer functions.
  • Employ the Final Value Theorem to find the asymptotic value of function when time tends to infinity.

Part 2Formula sheet

Laplace pairs

$$\delta\to1,\ \ 1\to\tfrac1s,\ \ t^n\to\tfrac{n!}{s^{n+1}},\ \ e^{at}\to\tfrac1{s-a},\ \ t^ne^{at}\to\tfrac{n!}{(s-a)^{n+1}}$$ $$\cos\omega t\to\tfrac{s}{s^2+\omega^2},\quad \sin\omega t\to\tfrac{\omega}{s^2+\omega^2}$$ $$e^{at}\cos\omega t\to\tfrac{s-a}{(s-a)^2+\omega^2},\quad e^{at}\sin\omega t\to\tfrac{\omega}{(s-a)^2+\omega^2}$$

Properties

$$e^{at}g\to G(s-a),\quad \dot g\to sG - g(0),\quad \ddot g\to s^2G - sg(0) - \dot g(0)$$ $$\textstyle\int_0^tg\to G/s,\quad g\otimes u\to GU,\quad g(t-t_0)1_+(t-t_0)\to e^{-st_0}G$$

Partial fractions

$$a_j = [G(s)(s-\lambda_j)]_{s=\lambda_j},\qquad k = G(\infty)\to k\delta(t)$$ $$\tfrac{\gamma}{s-a-i\omega} + \tfrac{\bar\gamma}{s-a+i\omega}\to 2\Re\gamma\,e^{at}\cos\omega t - 2\Im\gamma\,e^{at}\sin\omega t$$ $$\tfrac{c}{(s-\lambda)^m}\to c\tfrac{t^{m-1}}{(m-1)!}e^{\lambda t}$$

Transfer functions

$$Y = GU,\quad y = g\otimes u,\quad \text{stable}\iff \Re\lambda < 0\ \forall\text{ poles}$$ $$\text{FVT: } y(\infty) = G(0)u_0\ \text{(stable } G\text{ only)}$$ $$Z_R = R,\ Z_L = Ls,\ Z_C = \tfrac1{Cs},\quad G = \tfrac{Z_2}{Z_1 + Z_2}$$ $$m\ddot y + c\dot y + ky = u:\ \omega_n = \sqrt{k/m},\ \zeta = \tfrac{c}{2\sqrt{mk}}$$

LTI systems and the delta function

$$\text{linear: superposition};\quad \text{TI: } u(t-\tau)\mapsto y(t-\tau)$$ $$\textstyle\int h(t)\delta(t - t_0)dt = h(t_0),\quad g\otimes\delta = g,\quad \mathcal L\{\delta(t-t_0)\} = e^{-st_0}$$ $$G = \mathcal L\{g\} = Y/U\ \ (\text{zero ICs}),\quad u = \mathcal L^{-1}\{Y/G\}$$

Poles and time functions; domain

$$-a\to e^{-at},\quad 0\to\text{step},\quad \pm i\omega\to\cos,\sin\omega t$$ $$\sigma\pm i\omega\to e^{\sigma t}(B\cos\omega t + C\sin\omega t),\quad \text{double }\lambda\to te^{\lambda t}$$ $$\text{ROC: } \Re s > \max_k\Re(\text{pole}_k)$$

Part 3Common mistakes

  • Forgetting \(\omega\) in \(\sin\): \(\mathcal L\{\sin5t\} = 5/(s^2+25)\), not \(1/(s^2+25)\).
  • Shift without a step: \(e^{-st_0}G(s)\) is the transform of \(g(t-t_0)1_+(t-t_0)\) only.
  • Initial conditions: \(\mathcal L\{\ddot y\} = s^2Y - sy(0) - \dot y(0)\). Watch the signs and include both terms.
  • Improper or same-degree \(G\): pull out the direct term first; it becomes \(k\delta(t)\).
  • Complex residues: \(\gamma\) gives \(+2\Re\gamma\cos\) and \(-2\Im\gamma\sin\). The minus sign is easy to drop.
  • Final value theorem without stability: poles at 0, on the imaginary axis or in the right half-plane mean no final value.
  • Transfer functions assume zero initial conditions. With nonzero initial conditions, transform the ODE itself.
  • Nonlinear "looking linear": \(y = 3u + 1\) is not linear (zero input gives a nonzero output), and \(y = t\,u\) is linear but not time invariant.

Part 4Exam-style problems

Problems

(a) Find \(\mathcal L\{3e^{-2t}\cos4t - t^2e^{t} + 5\}\).

(b) Find the transform of the pulse \(g = 2\) on \([1,3]\), zero elsewhere.

(c) Use transforms to compute \(e^{-2t}\otimes e^{-5t}\).

Solution

(a) \(\frac{3(s+2)}{(s+2)^2 + 16} - \frac{2}{(s-1)^3} + \frac5s\).

(b) \(g = 2\cdot1_+(t-1) - 2\cdot1_+(t-3)\), so \(G = \frac{2(e^{-s} - e^{-3s})}{s}\).

(c) \(\frac{1}{(s+2)(s+5)} = \frac{1/3}{s+2} - \frac{1/3}{s+5}\), so \(e^{-2t}\otimes e^{-5t} = \tfrac13(e^{-2t} - e^{-5t})\).

(a) Invert \(G(s) = \dfrac{s^2 + 2s + 10}{s(s+1)(s+5)}\).

(b) Invert \(G(s) = \dfrac{10}{s(s^2 + 2s + 5)}\) and write \(g\) with real functions.

(c) Solve \(\ddot y + 4\dot y + 3y = 6\), \(y(0) = 0\), \(\dot y(0) = 2\).

Solution

(a) Cover-up: \(a_0 = \frac{10}{5} = 2\), \(a_{-1} = \frac{9}{(-1)(4)} = -\frac94\), \(a_{-5} = \frac{25}{(-5)(-4)} = \frac54\). \(g = 2 - \tfrac94e^{-t} + \tfrac54e^{-5t}\). (Check: the residues sum to 1, the leading coefficient ratio.)

(b) Poles \(0, -1\pm2i\). \(a_0 = 2\); \(\gamma = \left.\frac{10}{s(s+1+2i)}\right|_{-1+2i} = \frac{10}{(-1+2i)(4i)} = -1 + \tfrac12i\). Lemma 1: \(g = 2 - 2e^{-t}\cos2t - e^{-t}\sin2t\). Check \(g(0) = 0\). ✓

(c) \((s^2 + 4s + 3)Y - 2 = 6/s\), so \(Y = \frac{2s + 6}{s(s+1)(s+3)} = \frac{2}{s(s+1)}\) (the \(s+3\) cancels!). Then \(y = 2 - 2e^{-t}\). Check: \(y(0) = 0\), \(\dot y(0) = 2\), \(y(\infty) = 6/3 = 2\). ✓

A series loop has a source \(u\), \(R = 2\,\Omega\), \(L = 1\) H and \(C = 0.2\) F; \(y\) is the capacitor voltage.

(a) Find \(G(s)\), its poles, and whether it is stable. (b) Find \(y(t)\) for \(u = 10\) V from rest. (c) What is the final inductor voltage? (d) Find the input impedance \(Z(s)\).

(e) A mass–spring–damper has \(m = 2\), \(c = 8\), \(k = 40\) and force \(u = 20\) N. Find \(y(\infty)\), \(\omega_n\), \(\zeta\) and the poles.

Solution

(a) \(G = \frac{1}{LCs^2 + RCs + 1} = \frac{1}{0.2s^2 + 0.4s + 1} = \frac{5}{s^2 + 2s + 5}\); poles \(-1\pm2i\): stable.

(b) \(Y = \frac{50}{s(s^2+2s+5)}\), which is 5 times Problem 2(b): \(y = 10 - 10e^{-t}\cos2t - 5e^{-t}\sin2t\).

(c) \(G_L(0) = 0\), so 0 V (all 10 V end up across the capacitor).

(d) \(Z = 2 + s + \frac{5}{s} = \frac{s^2 + 2s + 5}{s}\).

(e) \(y(\infty) = 20/40 = 0.5\) m; \(\omega_n = \sqrt{20} \approx 4.47\); \(\zeta = \frac{8}{2\sqrt{80}} \approx 0.447\); poles of \(2s^2 + 8s + 40\): \(-2 \pm 4i\).

(a) Classify each system as linear or not, and time invariant or not: \(y = 2u(t-1)\); \(y = u(t) + 2\); \(y = t\,u(t)\).

(b) An LTI system has impulse response \(g(t) = 2e^{-t} - 2e^{-3t}\). Find \(G(s)\), its poles, and \(G(0)\).

(c) Find its step response from rest. (d) Which input, applied from rest, produces \(y(t) = 4(1 - e^{-t})\)?

(e) Another system has poles \(-2 \pm 5i\) only. What kind of function is its impulse response?

Solution

(a) \(2u(t-1)\): linear and time invariant. \(u + 2\): not linear (zero input gives 2), time invariant. \(t\,u\): linear, time varying.

(b) \(G = \frac{2}{s+1} - \frac{2}{s+3} = \frac{4}{(s+1)(s+3)}\); poles \(-1, -3\) (stable); \(G(0) = \tfrac43\).

(c) \(Y = \frac{4}{s(s+1)(s+3)} = \frac{4/3}{s} - \frac{2}{s+1} + \frac{2/3}{s+3}\), so \(y = \tfrac43 - 2e^{-t} + \tfrac23e^{-3t}\). Check \(y(0) = 0\) ✓ and \(y(\infty) = G(0) = \tfrac43\) ✓.

(d) \(Y = \frac{4}{s(s+1)}\), so \(U = \frac{Y}{G} = \frac{4}{s(s+1)}\cdot\frac{(s+1)(s+3)}{4} = \frac{s+3}{s} = 1 + \frac3s\), i.e. \(u(t) = \delta(t) + 3\).

(e) \(e^{-2t}(B\cos5t + C\sin5t)\): a decaying oscillation at 5 rad/s with envelope \(e^{-2t}\).
