Part 1Learning objectives checklist

Sinusoid response and Bode plots (Lesson 9)

  • Find the steady-state response of a stable \(G\) to constants, sinusoids and sums of sinusoids.
  • Explain why the steady state needs stability, and compute \(G(i\omega)\) factor by factor (magnitude and angle).
  • Sketch magnitude and phase Bode plots from corner frequencies and slopes; convert gains to dB.
  • Find \(\omega_n\), \(\zeta\), poles, the resonance frequency \(\omega_r\) and the peak gain of a second-order system.

Filters (Lesson 10)

  • Describe ideal low-, high-, band-pass and band-stop filters and why they are not realizable.
  • Write the low-pass Butterworth filter, its poles and \(|G(i\omega)|^2 = 1/(1 + (\omega/\omega_c)^{2n})\).
  • Choose a Butterworth order for a required attenuation; build high-pass and band-pass filters by substitution.
  • Recognize all-pass filters (Blaschke products) and compute their phase.

Fourier transform (Lesson 11)

  • Compute Fourier transforms of pulses, one- and two-sided exponentials and Gaussians, and invert rational transforms.
  • Use the shift, modulation, scaling, derivative and convolution properties and Parseval's identity.
  • Relate \(\hat G(\omega)\) to \(G(i\omega)\); explain the ideal filter's noncausal impulse response.
  • Apply the Nyquist rate \(T < \pi/\omega_{\max}\) and predict alias frequencies.
  • State and apply the uncertainty principle \(\sigma_g\sigma_G \ge \tfrac12\).

Part 2Formula sheet

Steady state

$$u = \gamma\cos(\omega t + \varphi)\Rightarrow y_{ss} = \gamma|G(i\omega)|\cos(\omega t + \varphi + \angle G(i\omega))$$ $$|i\omega + a| = \sqrt{\omega^2 + a^2},\quad \angle(i\omega + a) = \arctan(\omega/a)\ (a>0)$$

Bode

$$\text{dB} = 20\log_{10}|G|,\quad \text{pole: } -20\text{ dB/dec},\ -\tfrac\pi2;\quad \text{zero: } +20,\ +\tfrac\pi2$$ $$\text{slope at high } \omega = -20(\#p - \#z)\text{ dB/dec}$$

Second order

$$\frac{\omega_n^2}{s^2 + 2\zeta\omega_ns + \omega_n^2},\quad \lambda = -\zeta\omega_n \pm i\omega_n\sqrt{1-\zeta^2}$$ $$\omega_r = \omega_n\sqrt{1 - 2\zeta^2},\quad |G(i\omega_r)| = \frac{1}{2\zeta\sqrt{1-\zeta^2}},\quad |G(i\omega_n)| = \frac{1}{2\zeta}$$

Butterworth

$$|G|^2 = \frac{1}{1 + (\omega/\omega_c)^{2n}},\quad \lambda_k = i\omega_ce^{i(\pi + 2\pi k)/2n}$$ $$\text{HP: } \tfrac{s^n}{d(s)},\quad \text{BP: } G_1\!\left(\tfrac{s^2 + ab}{s(b-a)}\right),\quad n \ge \tfrac{\log(10^{A/10} - 1)}{2\log(\omega_s/\omega_c)}$$

Fourier transform

$$\hat G = \int e^{-i\omega t}g\,dt,\quad g = \tfrac1{2\pi}\int e^{i\omega t}\hat G\,d\omega$$ $$\text{pulse }[-\mu,\mu]\to\tfrac{2\sin\omega\mu}{\omega},\ e^{-a|t|}\to\tfrac{2a}{a^2+\omega^2},\ e^{-at^2}\to\sqrt{\tfrac\pi a}e^{-\omega^2/4a}$$ $$g(t - t_0)\to e^{-i\omega t_0}\hat G,\ e^{i\omega_0t}g\to\hat G(\omega - \omega_0),\ \dot g\to i\omega\hat G$$

Energy, sampling, uncertainty

$$\int|g|^2dt = \tfrac{1}{2\pi}\int|\hat G|^2d\omega$$ $$T < \pi/\omega_{\max}\ \ (F_s > 2f_{\max}),\qquad \sigma_g\sigma_G \ge \tfrac12$$

Part 3Common mistakes

  • Unstable \(G\): there is no steady state, and the Bode plot does not describe a measurable response.
  • Phase quadrant: a negative gain adds \(\pi\); a right-half-plane zero subtracts phase instead of adding it.
  • dB: magnitudes use \(20\log_{10}\), powers \(10\log_{10}\). A factor of 10 is 20 dB; \(1/\sqrt2\) is −3 dB.
  • Resonance: \(\omega_r \ne \omega_n\), and there is no peak at all when \(\zeta > 1/\sqrt2\).
  • Hz vs rad/s: Nyquist is \(F_s > 2f_{\max}\) in Hz, or \(T < \pi/\omega_{\max}\) in rad/s.
  • The \(2\pi\) in Parseval and the inverse transform (and \(\frac1{|a|}\) in scaling).

Part 4Exam-style problems

Problems

\(G(s) = \dfrac{20}{(s+2)(s+10)}\).

(a) Find \(y_{ss}\) for \(u = 3 + 2\cos2t\). (b) Sketch the asymptotic magnitude Bode plot. (c) Find \(20\log_{10}|G(10i)|\).

Solution

(a) \(G(0) = 1\). \(G(2i) = \frac{20}{(2+2i)(10+2i)} = \frac{20}{16 + 24i}\): \(|G| = 0.693\), \(\angle G = -\arctan(24/16) = -0.983\). So \(y_{ss} = 3 + 1.387\cos(2t - 0.983)\).

(b) 0 dB up to \(\omega = 2\), then \(-20\) dB/decade to \(\omega = 10\) (reaching about \(-14\) dB), then \(-40\) dB/decade.

(c) \(|G(10i)| = \frac{20}{|2+10i||10+10i|} = \frac{20}{10.2\cdot14.14} = 0.139\), i.e. \(-17.2\) dB (the asymptote says \(-14\); each corner is about 3 dB below its asymptote nearby).

\(G(s) = \dfrac{64}{s^2 + 4s + 64}\). Find \(\omega_n\), \(\zeta\), the poles, \(\omega_r\) and the peak gain in dB. What is \(y_{ss}\) for \(u = \cos(8t)\)?

Solution

\(\omega_n = 8\), \(\zeta = 4/16 = 0.25\), poles \(-2 \pm i\sqrt{60} \approx -2 \pm 7.75i\). \(\omega_r = 8\sqrt{1 - 0.125} = 7.48\), peak \(\frac{1}{0.5\sqrt{0.9375}} = 2.07\) (6.3 dB). At \(\omega = \omega_n = 8\): \(G(8i) = \frac{64}{32i} = -2i\), so \(y_{ss} = 2\cos(8t - \pi/2) = 2\sin8t\).

(a) Give the second-order low-pass Butterworth filter with \(\omega_c = 10\) and its poles. (b) Its gain at \(\omega = 30\) in dB. (c) The smallest order that attenuates \(\omega = 50\) by 40 dB. (d) Find \(y_{ss}\) (approximately) for \(u = \cos2t + \cos50t\) through the filter from (a).

Solution

(a) \(G = \frac{100}{s^2 + 10\sqrt2s + 100}\), poles \(10e^{\pm i3\pi/4} = -7.07 \pm 7.07i\).

(b) \(1/\sqrt{1 + 3^4} = 0.110\), i.e. \(-19.1\) dB.

(c) \(n \ge \frac{\log_{10}(10^4 - 1)}{2\log_{10}5} = 2.86\), so \(n = 3\).

(d) \(|G(2i)| = 1/\sqrt{1 + 0.2^4} = 0.9992\) and \(|G(50i)| = 1/\sqrt{1 + 625} = 0.040\). So \(y_{ss} \approx \cos(2t - 0.29) + 0.04\cos(50t + \phi)\): the 50 rad/s component is reduced 25-fold. (\(G(2i) = \frac{100}{96 + 20\sqrt2\,i}\), so \(\angle G(2i) = -\arctan\frac{20\sqrt2}{96} = -0.29\).)

(a) Find \(\hat G\) for \(g = e^{-3|t|}\). (b) Find the transform of \(g(t-2)\) and of \(\cos(5t)g(t)\). (c) Use Parseval to evaluate \(\int\frac{36}{(9 + \omega^2)^2}d\omega\). (d) What sampling rate is needed for a signal band-limited to 300 Hz? (e) A Gaussian pulse has \(\sigma_G = 4\) rad/s; what is its \(\sigma_g\)?

Solution

(a) \(\frac{6}{9 + \omega^2}\). (b) \(e^{-2i\omega}\frac{6}{9+\omega^2}\), and \(\tfrac12\left[\frac{6}{9 + (\omega-5)^2} + \frac{6}{9 + (\omega+5)^2}\right]\).

(c) \(\int|g|^2 = 2\int_0^\infty e^{-6t}dt = \tfrac13\), so the integral is \(2\pi\cdot\tfrac13 = \tfrac{2\pi}{3}\).

(d) \(F_s > 600\) Hz. (e) Gaussians achieve equality: \(\sigma_g = \frac{1}{2\cdot4} = 0.125\) s.
