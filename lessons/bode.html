Sinusoid Response & Bode Plots

Drive a stable system with a sinusoid and, once the transient dies out, the output is a sinusoid at the same frequency, scaled by \(|G(i\omega)|\) and shifted by \(\angle G(i\omega)\). The function \(G(i\omega)\) is the system's frequency response, and the Bode plot is how engineers draw it. This lesson covers the steady-state response, sketching Bode plots from straight-line asymptotes, natural frequency and damping ratio, and resonance.

Section 9.1The steady-state response

Let \(G\) be stable, so all its poles have \(\Re\lambda < 0\), and apply \(u(t) = e^{i\omega t}\). Then \(Y(s) = \frac{G(s)}{s - i\omega} = \frac{G(i\omega)}{s - i\omega} + (\text{terms at the poles of } G)\). The pole terms decay, leaving the steady-state response \(y_{ss}(t) = G(i\omega)e^{i\omega t}\). Taking real and imaginary parts, with \(G(i\omega) = |G(i\omega)|e^{i\phi(\omega)}\):

$$u = \gamma\cos(\omega t + \varphi)\;\Rightarrow\; y_{ss} = \gamma|G(i\omega)|\cos\big(\omega t + \varphi + \phi(\omega)\big),$$ $$u = \gamma\sin(\omega t + \varphi)\;\Rightarrow\; y_{ss} = \gamma|G(i\omega)|\sin\big(\omega t + \varphi + \phi(\omega)\big).$$

\(|G(i\omega)|\) is the gain and \(\phi(\omega) = \angle G(i\omega)\) the phase shift. A constant input \(a = a\cos(0t)\) gives \(G(0)a\), which is the final value theorem again. Stability is essential: if \(G\) has a pole with \(\Re\lambda\ge0\), its term never dies out and there is no steady state. For a real \(G\), \(G(-i\omega) = \overline{G(i\omega)}\), so we only need \(\omega \ge 0\).

To evaluate \(G(i\omega)\) by hand, work factor by factor: \(|G(i\omega)| = |K|\frac{\prod|i\omega - z_j|}{\prod|i\omega - p_k|}\) and \(\angle G(i\omega) = \angle K + \sum\angle(i\omega - z_j) - \sum\angle(i\omega - p_k)\), where \(|i\omega + a| = \sqrt{\omega^2 + a^2}\) and \(\angle(i\omega + a) = \arctan(\omega/a)\) for \(a > 0\). Example from the notes: \(G(s) = \frac{15(s-4)}{(s+2)(s+3)}\) has \(G(0) = -10\), \(|G(i\omega)| = 10\sqrt{\frac{1 + \omega^2/16}{(1+\omega^2/4)(1 + \omega^2/9)}}\) and \(\phi(\omega) = \pi - \arctan\frac\omega4 - \arctan\frac\omega2 - \arctan\frac\omega3\). (The right-half-plane zero subtracts phase, and the negative gain adds \(\pi\).) For \(u = -2 + 6\cos5t\), \(y_{ss} = 20 + 18.35\cos(5t + 0.025)\).

Section 9.2Sums of sinusoids and periodic inputs

By linearity, each frequency passes through on its own:

$$u = a + \sum_k\big(\alpha_k\cos(\omega_kt + \varphi_k) + \beta_k\sin(\omega_kt + \varphi_k)\big)\;\Rightarrow\; y_{ss} = G(0)a + \sum_k|G(i\omega_k)|\big(\alpha_k\cos(\omega_kt + \varphi_k + \phi_k) + \beta_k\sin(\omega_kt + \varphi_k + \phi_k)\big).$$

A periodic input is a Fourier series \(u = \sum a_ke^{-ik\omega_0t}\), so the steady-state output is the Fourier series \(\sum a_kG(-ik\omega_0)e^{-ik\omega_0t}\) (the notes' sign convention puts \(-ik\omega_0\) in \(G\)). A square wave through a low-pass system loses its high harmonics and comes out rounded. Conversely, measuring the steady-state amplitude and phase at several frequencies recovers \(G(i\omega_k)\) experimentally. Section 8.2 of the notes fits \(m, c, k\) of a mass–spring–damper this way by least squares.

Section 9.3Bode plots

The Bode plot of \(G\) is two graphs against \(\log_{10}\omega\): the magnitude \(20\log_{10}|G(i\omega)|\) in decibels (dB), and the phase \(\angle G(i\omega)\). Logarithms turn products into sums, so the Bode plot of a product is the sum of the factors' plots. A factor of 10 in gain is \(+20\) dB, a factor of \(\sqrt2\) is about 3 dB, and a decade is a factor of 10 in frequency. In MATLAB: bode(tf(num,den)).

Section 9.5Natural frequency and damping ratio

A pair of complex poles is written in standard form

$$G(s) = \frac{\omega_n^2}{s^2 + 2\zeta\omega_ns + \omega_n^2},\qquad \lambda = -\zeta\omega_n \pm i\omega_n\sqrt{1 - \zeta^2},\qquad |\lambda| = \omega_n,$$

with natural frequency \(\omega_n\) and damping ratio \(\zeta\), stable when \(\zeta > 0\). Setting \(\zeta = \cos\theta\) puts the poles at \(-\omega_ne^{\mp i\theta}\): the angle from the negative real axis measures how lightly damped the system is. To read \(\omega_n, \zeta\) from \(s^2 + bs + c\): \(\omega_n = \sqrt c\) and \(\zeta = b/(2\sqrt c)\). On the Bode plot the magnitude is about 0 dB well below \(\omega_n\), equals \(-20\log_{10}(2\zeta)\) at \(\omega_n\) (a peak of \(+34\) dB when \(\zeta = 0.01\)), and falls at \(-40\) dB/decade above. The phase passes \(-\pi/2\) at \(\omega_n\), and the smaller \(\zeta\), the more sharply it drops.

Section 9.6Resonance

The resonance frequency \(\omega_r\) maximizes \(|G(i\omega)|\). For the standard second-order system, minimizing \(|\omega_n^2 - \omega^2 + 2i\zeta\omega_n\omega|^2 = (\omega^2 - \omega_n^2(1-2\zeta^2))^2 + 4\omega_n^4\zeta^2(1-\zeta^2)\) gives

$$\omega_r = \omega_n\sqrt{1 - 2\zeta^2},\qquad |G(i\omega_r)| = \frac{1}{2\zeta\sqrt{1-\zeta^2}}\qquad\left(0 < \zeta \le \tfrac{1}{\sqrt2}\right).$$

For \(\zeta > 1/\sqrt2\) the maximum is at \(\omega = 0\) and there is no resonance peak. \(\omega_r\) is slightly below \(\omega_n\), and close to it for small \(\zeta\). Lightly damped structures driven near \(\omega_r\) respond with huge amplitude. The notes' bus-suspension and mass–spring examples show how adding a tuned mass with \(k_2 = m_2\omega^2\) can cancel the steady-state response to a disturbance at frequency \(\omega\) entirely.

Section 9.7Worked examples

Worked examples

\(G(s) = \frac{4}{s+2}\), \(u(t) = 3\cos(2t)\). Find \(y_{ss}\).

Solution

\(G(2i) = \frac{4}{2 + 2i} = \frac{4}{2\sqrt2e^{i\pi/4}} = \sqrt2e^{-i\pi/4}\). So \(y_{ss} = 3\sqrt2\cos(2t - \pi/4)\). The input is at the corner frequency, so the gain is \(1/\sqrt2\) of the DC gain 2 and the phase lag is \(\pi/4\).

\(G(s) = \frac{10}{(s+1)(s+10)}\), \(u(t) = 2 - 5\sin(10t)\). Find \(y_{ss}\).

Solution

\(G(0) = 1\), so the constant gives 2. \(G(10i) = \frac{10}{(1 + 10i)(10 + 10i)}\): \(|G| = \frac{10}{\sqrt{101}\cdot10\sqrt2} = 0.0704\) and \(\angle G = -\arctan10 - \pi/4 = -2.256\) rad.

$$y_{ss}(t) = 2 - 0.352\sin(10t - 2.256).$$

Sketch the magnitude Bode plot of \(G(s) = \frac{100(s+1)}{(s+10)(s+100)}\).

Solution

Time-constant form: \(G = \frac{100}{1000}\cdot\frac{1 + s}{(1 + s/10)(1 + s/100)}\), so \(|G(0)| = 0.1\), i.e. \(-20\) dB. The line is flat at \(-20\) dB up to \(\omega = 1\), rises at \(+20\) dB/decade to 0 dB at \(\omega = 10\), is flat at 0 dB to \(\omega = 100\), then falls at \(-20\) dB/decade. (Load the "lead" preset in Interactive 2.)

\(G(s) = \frac{25}{s^2 + 4s + 25}\). Find \(\omega_n\), \(\zeta\), the poles, \(\omega_r\), the peak gain, and \(|G(i\omega_n)|\).

Solution

\(\omega_n = 5\), \(\zeta = 4/10 = 0.4\). Poles \(-2 \pm i\sqrt{21}\). \(\omega_r = 5\sqrt{1 - 0.32} = 4.12\), with peak \(\frac{1}{0.8\sqrt{0.84}} = 1.364\) (2.7 dB). At \(\omega_n\): \(1/(2\zeta) = 1.25\).

\(G(s) = \frac{1}{s^2 + 4}\) is driven by \(\cos(t)\). What is the steady-state response?

Solution

\(G\) has poles \(\pm2i\), so it is not stable and the free oscillation at 2 rad/s never decays. The formula \(|G(i)|\cos(t + \angle G(i)) = \tfrac13\cos t\) is only part of the output: from rest, \(y = \tfrac13(\cos t - \cos 2t)\). Driven at \(\omega = 2\), the output would grow like \(t\sin2t\).
