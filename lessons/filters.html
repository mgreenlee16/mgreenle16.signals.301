Filters: Ideal, Butterworth & All-Pass

A filter is a system designed for its frequency response: pass some frequencies, block others. This lesson defines the ideal low-, high-, band-pass and band-stop filters and explains why they cannot be built. It then constructs the Butterworth filters that approximate them, shows how to choose the order and transform a low-pass design into the other types, and closes with all-pass filters, which change only the phase.

Section 10.1Ideal filters

An ideal low-pass filter with cutoff \(\omega_c\) has \(G(i\omega) = 1\) for \(|\omega| < \omega_c\) and \(0\) for \(|\omega| > \omega_c\). An input \(u = \sum a_ke^{i\omega_kt}\) then has steady-state output \(\sum_{|\omega_k|<\omega_c}a_ke^{i\omega_kt}\): the low frequencies pass untouched and the rest vanish. The ideal high-pass filter keeps \(|\omega| > \omega_c\), the band-pass filter keeps \(a < |\omega| < b\), and the band-stop filter removes that band.

Ideal filters are not rational functions, so they have no finite-dimensional realization. Lesson 11 shows that the ideal low-pass impulse response is \(\frac{\sin\omega_ct}{\pi t}\), which is nonzero for \(t < 0\): the filter would have to respond before the input arrives. Real filters trade sharpness for causality. A first-order low-pass \(\frac{\omega_c}{s + \omega_c}\) is the crudest approximation, the system \(\dot y = -\omega_cy + \omega_cu\).

Section 10.2Low-pass Butterworth filters

The \(n\)-th order low-pass Butterworth filter with cutoff \(\omega_c\) is

$$G(s) = \frac{\omega_c^n}{d(s)},\qquad d(s) = \prod_{k=0}^{n-1}\big(s - \lambda_k\big),\qquad \lambda_k = i\omega_ce^{i(\pi + 2\pi k)/2n}.$$

The poles are the left half of \(2n\) equally spaced points on the circle of radius \(\omega_c\). They start at angle \(\pi/2 + \pi/2n\) and are spaced \(\pi/n\) apart, so the filter is stable. Its magnitude is maximally flat:

$$|G(i\omega)|^2 = \frac{1}{1 + (\omega/\omega_c)^{2n}},\qquad |G(0)| = 1,\qquad |G(i\omega_c)| = \tfrac{1}{\sqrt2}\ (-3\text{ dB}).$$

Above the cutoff the magnitude falls at \(-20n\) dB/decade. Orders 1 and 2 are \(\frac{\omega_c}{s + \omega_c}\) and \(\frac{\omega_c^2}{s^2 + \sqrt2\omega_cs + \omega_c^2}\), the latter a second-order system with \(\zeta = 1/\sqrt2\), the largest damping with no resonance peak. MATLAB: [num,den] = butter(n,wc,'s').

Section 10.3Choosing the order

To attenuate a frequency \(\omega_s > \omega_c\) by at least \(A\) dB, require \(10\log_{10}\big(1 + (\omega_s/\omega_c)^{2n}\big) \ge A\):

$$n \ge \frac{\log_{10}\big(10^{A/10} - 1\big)}{2\log_{10}(\omega_s/\omega_c)},$$

rounded up. Higher order gives a sharper edge, but costs more poles (more circuitry or computation) and more phase lag near the cutoff.

Section 10.4High-pass, band-pass and band-stop

Every Butterworth filter comes from the unit-cutoff low-pass \(G_1(s)\) by substituting a function of \(s\):

  • Low-pass, cutoff \(\omega_c\): \(G_1(s/\omega_c)\).
  • High-pass: \(H(s) = G_1(\omega_c/s) = \frac{s^n}{d(s)}\) with the same denominator, and \(|H(i\omega)|^2 = \frac{(\omega/\omega_c)^{2n}}{1 + (\omega/\omega_c)^{2n}}\).
  • Band-pass on \([a,b]\): \(P(s) = G_1\big(m(s)\big)\) with \(m(s) = \frac{s^2 + ab}{s(b-a)}\). Its degree is \(2n\), it equals 1 at the center \(\sqrt{ab}\), and \(1/\sqrt2\) at \(a\) and \(b\). For \(n = 2\): \(P(s) = \frac{s^2(b-a)^2}{s^4 + \sqrt2(b-a)s^3 + (a^2+b^2)s^2 + \sqrt2ab(b-a)s + a^2b^2}\).
  • Band-stop on \([a,b]\): \(G_1\big(1/m(s)\big)\), which is zero at \(\sqrt{ab}\).

The substitution \(m\) maps the imaginary axis to itself, sending \(\pm a\) and \(\pm b\) to \(\pm1\). So the pass band of \(G_1\) becomes \([a,b]\), and stable poles stay stable.

Section 10.5Filtering a signal

By Section 9.2, a stable filter driven by \(u = \sum\gamma_k\cos(\omega_kt)\) settles to \(y_{ss} = \sum\gamma_k|G(i\omega_k)|\cos(\omega_kt + \phi(\omega_k))\). Designing a filter means making \(|G(i\omega_k)| \approx 1\) for the components you want and \(\approx 0\) for the rest. Check the actual gains: a second-order low-pass with \(\omega_c = 3\) passes \(\cos t\) at gain 0.994, \(\cos10t\) at 0.09 and \(\cos100t\) at 0.0009. The pass-band phase shifts are not zero, so the waveform is slightly delayed.

Section 10.6All-pass filters

An all-pass filter is a stable \(G\) with \(|G(i\omega)| = 1\) at every frequency. The building blocks are Blaschke products

$$B(s) = \gamma\prod_{j=1}^{n}\frac{s + \lambda_j}{s - \lambda_j} = \pm\frac{d(-s)}{d(s)},\qquad \Re\lambda_j < 0,\ \gamma = \pm1,$$

with the zeros the mirror images of the poles across the imaginary axis. For a real pole \(-a\), \(|i\omega - a| = |i\omega + a|\); complex poles come in conjugate pairs, and their factors cancel in magnitude pair by pair. So \(|B(i\omega)| = 1\). Example: \(B = \frac{(s-1)(s-2)(s-3-i)(s-3+i)}{(s+1)(s+2)(s+3+i)(s+3-i)}\). They pass every frequency at full strength but delay each by a different amount: \(\frac{s-a}{s+a}\) has phase \(\pi - 2\arctan(\omega/a)\). They are used to correct phase, and every stable rational \(G\) factors as a minimum-phase part times an all-pass part.

Section 10.7Worked examples

Worked examples

Find the poles and transfer function of the third-order low-pass Butterworth filter with \(\omega_c = 2\).

Solution

\(\lambda_k = 2ie^{i(\pi + 2\pi k)/6}\) for \(k = 0, 1, 2\): angles \(\pi/2 + \pi/6 = 2\pi/3\), \(\pi\), \(4\pi/3\). So the poles are \(-1 \pm i\sqrt3\) and \(-2\), and

$$G(s) = \frac{8}{(s+2)(s^2 + 2s + 4)} = \frac{8}{s^3 + 4s^2 + 8s + 8}.$$

Check \(|G(2i)|^2 = \frac{64}{|{-8i} - 16 + 16i + 8|^2} = \frac{64}{|{-8} + 8i|^2} = \frac{64}{128} = \tfrac12\). ✓

A low-pass Butterworth filter with \(\omega_c = 100\) must reduce a 1000 rad/s tone by at least 50 dB. What order?

Solution

\(n \ge \frac{\log_{10}(10^5 - 1)}{2\log_{10}10} = 2.5\), so \(n = 3\) (at least 60 dB of attenuation, consistent with \(-20n\) dB per decade).

Give the second-order high-pass Butterworth filter with cutoff 5, and its gain at \(\omega = 1\).

Solution

\(H(s) = \frac{s^2}{s^2 + 5\sqrt2s + 25}\). \(|H(i)|^2 = \frac{(1/5)^4}{1 + (1/5)^4} = \frac{1}{626}\), so \(|H(i)| = 0.040\) (\(-28\) dB).

\(u = 2 + 3\cos4t - \sin9t\) passes through an ideal low-pass filter with \(\omega_c = 5\). Find \(y_{ss}\) and its average power.

Solution

Frequencies 0 and 4 pass; 9 is removed: \(y_{ss} = 2 + 3\cos4t\). Power \(= 2^2 + 3^2/2 = 8.5\).

\(u = \cos t\) passes through \(B(s) = \frac{1 - s}{1 + s}\). Find \(y_{ss}\).

Solution

\(B(i) = \frac{1 - i}{1 + i} = -i = e^{-i\pi/2}\), so \(y_{ss} = \cos(t - \pi/2) = \sin t\). The magnitude is 1 and the phase lag is a quarter period. (Here \(\gamma = -1\) in the Blaschke form, giving phase \(-2\arctan\omega\).)
