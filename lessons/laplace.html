Lesson 5 · Exam 2

The Laplace Transform

Fourier series handle periodic signals. Systems that start at \(t = 0\), grow, decay or are switched on need a different tool: the Laplace transform. It turns derivatives into multiplication by \(s\) and convolution into multiplication, so a differential equation becomes algebra. This lesson builds the table of transform pairs and the properties you will use in every Exam 2 problem.

Section 5.1Definition and region of convergence

A function \(g(t)\) on \([0,\infty)\) is of exponential order if \(|g(t)| \le me^{\gamma t}\) for some constants \(m, \gamma\). Constants, exponentials, sinusoids and polynomials all qualify; \(e^{t^2}\) does not. For such a \(g\) the Laplace transform is

$$G(s) = (\mathcal Lg)(s) = \int_0^\infty e^{-st}g(t)\,dt,\qquad s = \sigma + i\omega \in \mathbb C.$$

The integral converges in the half-plane \(\Re s > \gamma\), the region of convergence, because there \(|e^{-st}g(t)| \le me^{(\gamma-\sigma)t}\) decays. Capital letters denote transforms: \(G = \mathcal Lg\), \(U = \mathcal Lu\), \(Y = \mathcal Ly\). The transform only looks at \(t \ge 0\), and \(g\) and \(G\) determine each other uniquely, so the inverse transform \(g = \mathcal L^{-1}G\) is well defined.

The transform is linear, \(\mathcal L(\alpha g + \beta h) = \alpha G + \beta H\), because the integral is. That is what lets us build transforms of complicated signals from a short table.

Specifying the domain. Always state where the transform is defined. For \(e^{at}\) it is \(\Re s > \Re a\): the integrand \(e^{(a-s)t}\) must decay. Constants, \(t^n\) and \(\cos\omega t\) need \(\Re s > 0\). For a sum, the domain is the intersection, \(\Re s\) greater than the largest real part among the poles. Example: \(g = 2 + e^{3t} - e^{-5t}\cos t\) has \(G(s) = \frac2s + \frac{1}{s-3} - \frac{s+5}{(s+5)^2+1}\), defined for \(\Re s > 3\). The formula for \(G\) makes sense at other \(s\) (except the poles), but the integral only converges in this half-plane.

Section 5.2The basic pairs

Everything starts from the exponential. For any complex \(a\) and \(\Re s > \Re a\),

$$\mathcal L\{e^{at}\} = \int_0^\infty e^{(a-s)t}\,dt = \frac{1}{s-a}.$$

With \(a = 0\) this gives the unit step, \(\mathcal L\{1_+(t)\} = 1/s\). Writing sinusoids with Euler's formula and using linearity gives

$$\mathcal L\{\cos\omega t\} = \frac{1}{2}\left(\frac1{s-i\omega} + \frac1{s+i\omega}\right) = \frac{s}{s^2+\omega^2},\qquad \mathcal L\{\sin\omega t\} = \frac{\omega}{s^2+\omega^2}.$$

Integration by parts and induction give the powers, \(\mathcal L\{t^n\} = n!/s^{n+1}\), and \(\cos(a+b)\) gives a phase-shifted sinusoid, \(\mathcal L\{\cos(\omega t + \phi)\} = \frac{s\cos\phi - \omega\sin\phi}{s^2+\omega^2}\).

Notice where the poles are (the values of \(s\) where \(G\) blows up). \(e^{at}\) has a pole at \(a\); \(\cos\omega t\) and \(\sin\omega t\) have poles at \(\pm i\omega\). The real part of a pole says how fast the signal grows or decays; the imaginary part says how fast it oscillates. Interactive 1 makes this concrete.

Section 5.3Multiplication by \(e^{at}\)

Multiplying a signal by \(e^{at}\) shifts its transform:

$$\mathcal L\{e^{at}g(t)\} = \int_0^\infty e^{-(s-a)t}g(t)\,dt = G(s-a).$$

Replace every \(s\) by \(s - a\). This immediately gives the damped sinusoids and the repeated-pole pairs:

$$\mathcal L\{e^{at}\cos\omega t\} = \frac{s-a}{(s-a)^2+\omega^2},\qquad \mathcal L\{e^{at}\sin\omega t\} = \frac{\omega}{(s-a)^2+\omega^2},\qquad \mathcal L\{t^ne^{at}\} = \frac{n!}{(s-a)^{n+1}}.$$

For example, \(g = 2e^{-3t} + 6e^{3t}\cos2t - 3e^{-2t}\sin4t\) has \(G(s) = \frac{2}{s+3} + \frac{6(s-3)}{(s-3)^2+4} - \frac{12}{(s+2)^2+16}\).

Section 5.4Derivatives and integrals

Integration by parts gives the rule that makes the Laplace transform useful for differential equations:

$$\mathcal L\{\dot g\} = sG(s) - g(0),\qquad \mathcal L\{\ddot g\} = s^2G(s) - sg(0) - \dot g(0),$$ $$\mathcal L\{g^{(n)}\} = s^nG(s) - s^{n-1}g(0) - s^{n-2}\dot g(0) - \cdots - g^{(n-1)}(0).$$

Differentiation is multiplication by \(s\), and the initial conditions appear automatically. Integration is division by \(s\):

$$\mathcal L\left\{\int_0^t g(x)\,dx\right\} = \frac{G(s)}{s}.$$

Check with \(g = \sin\omega t\): \(\int_0^t\sin\omega x\,dx = \frac{1 - \cos\omega t}{\omega}\), whose transform \(\frac1{\omega s} - \frac{s}{\omega(s^2+\omega^2)} = \frac{\omega}{s(s^2+\omega^2)}\) is indeed \(G(s)/s\).

Section 5.5Convolution

The convolution of two signals on \([0,\infty)\) is

$$(g\otimes u)(t) = \int_0^t g(t-\sigma)u(\sigma)\,d\sigma = \int_0^t g(\sigma)u(t-\sigma)\,d\sigma,$$

and its transform is the product: \(\mathcal L\{g\otimes u\} = G(s)U(s)\). Convolving is hard; multiplying is easy. This is the reason a linear time-invariant system is described by a transfer function (Lesson 7): its output is the convolution of the input with the impulse response.

Physical meaning. Think of the input as a train of tiny impulses: the slice \(u(\sigma)\,d\sigma\) applied at time \(\sigma\). An LTI system answers an impulse at time \(\sigma\) with the impulse response shifted to start there, \(g(t - \sigma)\). By linearity the output at time \(t\) is the sum of the responses to all earlier slices:

$$y(t) = \int_0^t \underbrace{g(t - \sigma)}_{\text{memory of an input }t-\sigma\text{ seconds ago}}\;u(\sigma)\,d\sigma.$$

So \(g\) is the system's memory: \(g(t - \sigma)\) weights how much an input from \(t - \sigma\) seconds ago still matters now. A fast-decaying \(g\) forgets quickly. Interactive 2 shows this weighting: flip \(g\), slide it to \(t\), multiply, and take the area.

For example, \(e^{-t}\otimes e^{-2t} = \int_0^t e^{-(t-\sigma)}e^{-2\sigma}d\sigma = e^{-t} - e^{-2t}\), and indeed \(\frac1{s+1}\cdot\frac1{s+2} = \frac1{s+1} - \frac1{s+2}\).

Section 5.6Delays, pulses and the delta function

Delaying a signal by \(t_0 \ge 0\) and switching it on at \(t_0\) multiplies its transform by \(e^{-st_0}\):

$$\mathcal L\{g(t-t_0)1_+(t-t_0)\} = e^{-st_0}G(s).$$

The rule needs the step: the delayed signal must be zero on \([0,t_0)\). Without it, \(e^{-(t-t_0)} = e^{t_0}e^{-t}\) simply has transform \(e^{t_0}/(s+1)\), not \(e^{-st_0}/(s+1)\). A pulse of height 1 on \([0,t_0]\) is \(1_+(t) - 1_+(t-t_0)\), so its transform is \(\frac{1 - e^{-st_0}}{s}\).

The Dirac delta \(\delta(t)\) is the limit of pulses of height \(n\) on \([0, 1/n]\): zero except at the origin, with area one. Its key property is \(\int h(t)\delta(t)\,dt = h(0)\), which gives

$$\mathcal L\{\delta\} = 1,\qquad \mathcal L\{\delta(t - t_0)\} = e^{-st_0},\qquad g\otimes\delta = g.$$

The properties of \(\delta\) you should be able to use:

  • Sifting: \(\int h(t)\delta(t - t_0)\,dt = h(t_0)\) for continuous \(h\); for example \(\int(t^2 + 1)\delta(t - 3)\,dt = 10\).
  • Area one, zero away from \(t_0\): \(\int\delta(t)\,dt = 1\), and \(h(t)\delta(t - t_0) = h(t_0)\delta(t - t_0)\).
  • Identity for convolution: \(g\otimes\delta = g\). Hitting a system with an impulse returns its impulse response, and \(g\otimes\delta(t - t_0) = g(t - t_0)1_+(t - t_0)\) delays it.
  • Derivative of the step: \(\delta = \frac{d}{dt}1_+(t)\), consistent with \(s\cdot\frac1s = 1\). A jump of size \(J\) in a signal puts \(J\delta\) in its derivative.
  • Direct terms: a proper transfer function with \(\deg n = \deg d\) has \(G(\infty) = k \ne 0\), and its impulse response contains \(k\delta(t)\) (Lesson 6).

Section 5.7Table of pairs and properties

Pairs

$$\delta(t)\to1,\quad 1\to\frac1s,\quad t^n\to\frac{n!}{s^{n+1}},\quad e^{at}\to\frac1{s-a}$$ $$\cos\omega t\to\frac{s}{s^2+\omega^2},\quad \sin\omega t\to\frac{\omega}{s^2+\omega^2}$$ $$t^ne^{at}\to\frac{n!}{(s-a)^{n+1}}$$ $$e^{at}\cos\omega t\to\frac{s-a}{(s-a)^2+\omega^2},\quad e^{at}\sin\omega t\to\frac{\omega}{(s-a)^2+\omega^2}$$

Properties

$$\alpha g + \beta h \to \alpha G + \beta H,\qquad e^{at}g \to G(s-a)$$ $$\dot g\to sG - g(0),\quad \ddot g \to s^2G - sg(0) - \dot g(0)$$ $$\int_0^t g \to \frac{G}{s},\qquad g\otimes u \to GU$$ $$g(t-t_0)1_+(t-t_0)\to e^{-st_0}G(s)$$

Section 5.8Worked examples

Worked examples

Find the Laplace transform of \(g(t) = 5 - 2e^{-3t} + 4\cos2t - \sin5t\).

Solution $$G(s) = \frac5s - \frac{2}{s+3} + \frac{4s}{s^2+4} - \frac{5}{s^2+25}.$$

Note the \(\omega = 5\) in the numerator of the sine term. Forgetting it is the most common slip.

Find \(\mathcal L\{t^2e^{-3t}\}\) and \(\mathcal L\{e^{2t}\cos(3t + \pi/4)\}\).

Solution

\(\mathcal L\{t^2\} = 2/s^3\), so \(\mathcal L\{t^2e^{-3t}\} = \frac{2}{(s+3)^3}\).

\(\mathcal L\{\cos(3t + \pi/4)\} = \frac{s\cos\frac\pi4 - 3\sin\frac\pi4}{s^2+9} = \frac{\sqrt2}{2}\cdot\frac{s - 3}{s^2+9}\). Replace \(s\) by \(s-2\): \(\frac{\sqrt2}{2}\cdot\frac{s-5}{(s-2)^2+9}\).

Find the transform of the pulse \(g = 3\) on \([1, 4]\), zero elsewhere.

Solution

\(g = 3\cdot1_+(t-1) - 3\cdot1_+(t-4)\). Each step is a delayed \(1/s\), so

$$G(s) = \frac{3(e^{-s} - e^{-4s})}{s}.$$

Directly: \(\int_1^4 3e^{-st}dt = \frac{3}{s}(e^{-s} - e^{-4s})\). ✓

\(y\) satisfies \(\ddot y + 4\dot y + 3y = 0\) with \(y(0) = 1\), \(\dot y(0) = 2\). Find \(Y(s)\).

Solution $$s^2Y - s - 2 + 4(sY - 1) + 3Y = 0 \;\Rightarrow\; Y(s) = \frac{s + 6}{s^2 + 4s + 3} = \frac{s+6}{(s+1)(s+3)}.$$

Lesson 6 inverts this: \(y = \tfrac52e^{-t} - \tfrac32e^{-3t}\). Check \(y(0) = 1\) ✓ and \(\dot y(0) = -\tfrac52 + \tfrac92 = 2\) ✓.

Compute \(e^{-t}\otimes\sin t\) using transforms.

Solution $$\frac{1}{s+1}\cdot\frac{1}{s^2+1} = \frac{1/2}{s+1} + \frac{-\tfrac12 s + \tfrac12}{s^2+1}\;\Rightarrow\; (e^{-t}\otimes\sin t)(t) = \tfrac12\left(e^{-t} - \cos t + \sin t\right).$$

At \(t = 0\) this is 0, as a convolution must be.
