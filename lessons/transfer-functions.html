Transfer Functions, Circuits & Stability

A linear time-invariant system is completely described by one function, its transfer function \(G(s) = Y(s)/U(s)\). This lesson finds transfer functions from differential equations, RLC circuits and impedance networks. It explains the impulse response and stability, uses the final value theorem to predict where outputs settle, and applies all of it to the mass–spring–damper.

Section 7.1LTI systems, transfer functions and the impulse response

A system maps an input \(u(t)\) to an output \(y(t)\). It is

  • linear if superposition holds: inputs \(u_1, u_2\) giving \(y_1, y_2\) means \(\alpha u_1 + \beta u_2\) gives \(\alpha y_1 + \beta y_2\). In particular zero input gives zero output, so \(y = 3u + 1\) and \(y = u^2\) are not linear.
  • time invariant if delaying the input delays the output by the same amount: \(u(t - \tau)\mapsto y(t - \tau)\). The system's rules do not depend on the clock, so \(y = t\,u(t)\) and \(\dot y + ty = u\) are not time invariant.

Constant-coefficient linear ODEs (starting from rest), RLC circuits and mass–spring–damper systems are LTI. For an LTI system starting at rest (all initial conditions zero),

$$Y(s) = G(s)U(s),\qquad y(t) = (g\otimes u)(t) = \int_0^t g(t-\sigma)u(\sigma)\,d\sigma.$$

\(G\) is the transfer function and \(g = \mathcal L^{-1}G\) is the impulse response: the output when \(u = \delta\), since then \(U = 1\) and \(y = g\otimes\delta = g\). The step response is the output for \(u = 1_+\), with \(Y = G(s)/s\).

Any two of \(G\), \(U\), \(Y\) determine the third:

  • From the impulse response: \(G = \mathcal L\{g\}\). For \(g = 3e^{-2t} - e^{-t}\), \(G = \frac{3}{s+2} - \frac{1}{s+1} = \frac{2s + 1}{(s+1)(s+2)}\).
  • From a measured input–output pair: \(G = Y/U\). A unit step producing \(y = 4(1 - e^{-3t})\) gives \(Y = \frac{12}{s(s+3)}\), so \(G = \frac{12}{s+3}\). The impulse response is also the derivative of the step response.
  • The output: \(y = \mathcal L^{-1}\{GU\}\). The input that produces a desired output: \(u = \mathcal L^{-1}\{Y/G\}\).

Section 7.2From a differential equation

Set every initial condition to zero and transform; each derivative becomes a power of \(s\). For \(y^{(3)} + 8\ddot y - 3\dot y + 2y = 4u\):

$$(s^3 + 8s^2 - 3s + 2)Y = 4U\quad\Rightarrow\quad G(s) = \frac{4}{s^3 + 8s^2 - 3s + 2}.$$

Derivatives of the input go in the numerator: \(\ddot y + a_1\dot y + a_0y = b_1\dot u + b_0u\) gives \(G = \frac{b_1s + b_0}{s^2 + a_1s + a_0}\). The poles of \(G\) are the roots of the characteristic polynomial of the ODE.

Section 7.3An RLC circuit

The element laws are \(v = Ri\) (resistor, ohms), \(v = L\,di/dt\) (inductor, henrys) and \(i = C\,dv/dt\) (capacitor, farads). Kirchhoff's voltage law says the voltages around a loop sum to zero, and the current law says the currents into a node sum to zero. (The notes write \(i_o\) for current, to keep \(i\) for \(\sqrt{-1}\).)

For a source \(u\) driving \(R\), \(L\) and \(C\) in series, with output \(y\) the capacitor voltage, KVL with zero initial conditions gives \(\left(R + Ls + \frac{1}{Cs}\right)I_o = U\) and \(Y = I_o/(Cs)\). So

$$G_C(s) = \frac{1}{LCs^2 + RCs + 1},\qquad G_R(s) = \frac{RCs}{LCs^2 + RCs + 1},\qquad G_L(s) = \frac{LCs^2}{LCs^2 + RCs + 1}$$

for the output taken across \(C\), \(R\) or \(L\). With \(L = C = 1\), \(R = 0.2\) and a 12 V step, the capacitor voltage is \(12 - 12e^{-0.1t}\cos(\sqrt{0.99}\,t) - 1.206e^{-0.1t}\sin(\sqrt{0.99}\,t)\). It rings at about 1 rad/s and settles to 12 V on the time scale of \(e^{-0.1t}\). Struck by lightning (\(u = \delta\)), the capacitor sees at most 0.86 V. The rest of the impulse appears across the inductor, whose transfer function has the same degree top and bottom and so passes a \(\delta(t)\) straight through.

Section 7.4Impedance

The impedance \(Z(s) = V(s)/I_o(s)\) of a passive network is its transfer function from current to voltage: \(Z_R = R\), \(Z_L = Ls\), \(Z_C = 1/(Cs)\). The admittance is \(1/Z\). Impedances combine like resistors:

$$Z_{\text{series}} = Z_1 + Z_2 + \cdots,\qquad Z_{\text{parallel}} = \left(\frac1{Z_1} + \frac1{Z_2} + \cdots\right)^{-1} = \frac{Z_1Z_2}{Z_1 + Z_2}\ (\text{two}).$$

A source driving \(Z_1\) and \(Z_2\) in series is a voltage divider: the voltage across \(Z_2\) has \(G = \frac{Z_2}{Z_1 + Z_2}\). Example from the notes: \(Z_1 = R_1 \parallel L\) and \(Z_2 = R_2\parallel C\) give \(Z_1 = \frac{R_1Ls}{Ls + R_1}\), \(Z_2 = \frac{R_2}{R_2Cs + 1}\), and

$$G(s) = \frac{R_2Ls + R_1R_2}{R_1R_2LCs^2 + (R_1 + R_2)Ls + R_1R_2}.$$

Two intuition checks: at DC (\(s = 0\)) capacitors are open circuits and inductors are short circuits; at very high frequency it is the reverse. Here \(G(0) = 1\), because the inductor shorts out \(R_1\).

Section 7.5Stability

A transfer function is stable if all its poles lie in the open left half-plane \(\Re\lambda < 0\). Then every term \(t^ke^{\lambda t}\) of the impulse response decays, \(\int_0^\infty|g|\,dt < \infty\), and bounded inputs give bounded outputs. A single pole with \(\Re\lambda \ge 0\) breaks stability, including poles on the imaginary axis: \(1/(s^2+1)\) is not stable even though its impulse response \(\sin t\) stays bounded, because driving it at its resonant frequency makes the output grow without bound.

Section 7.6The final value theorem

Theorem. If \(G\) is stable and \(u(t) = u_0\) (a constant for \(t \ge 0\)), then

$$\lim_{t\to\infty}y(t) = G(0)\,u_0.$$

Proof: \(Y = G(s)u_0/s = \frac{G(0)u_0}{s} + \Psi(s)\), where \(\Psi\) has only the (stable) poles of \(G\). So \(y = G(0)u_0 + \psi(t)\) with \(\psi \to 0\). The hypothesis matters. For \(G = \frac{2}{(s-1)(s+1)}\) a unit step gives \(y = e^t + e^{-t} - 2 \to \infty\), and one stable pole is not enough. For \(G = \frac{1}{s^2+1}\), \(y = 1 - \cos t\) oscillates forever. In both cases "\(G(0)u_0\)" is a meaningless number. Always check stability first.

For the RLC circuit \(G_C(0) = 1\), so the capacitor charges to the source voltage, while \(G_R(0) = G_L(0) = 0\): at steady state no current flows.

Section 7.7The mass–spring–damper

A mass \(m\) on a spring (constant \(k\), force \(-ky\)) and damper (coefficient \(c\), force \(-c\dot y\)) pushed by a force \(u\) obeys Newton's law \(m\ddot y = u - ky - c\dot y\):

$$m\ddot y + c\dot y + ky = u,\qquad G(s) = \frac{Y}{U} = \frac{1}{ms^2 + cs + k}.$$

With \(m, c, k > 0\) the poles are in the left half-plane, so a constant force \(u_0\) gives \(y(\infty) = G(0)u_0 = u_0/k\): the spring stretches until it balances the force. The velocity \(v = \dot y\) has \(V/U = sG(s)\), which is zero at \(s = 0\), so \(v(\infty) = 0\). Write \(ms^2 + cs + k = m(s^2 + 2\zeta\omega_ns + \omega_n^2)\), with natural frequency \(\omega_n = \sqrt{k/m}\) and damping ratio \(\zeta = \frac{c}{2\sqrt{mk}}\). Then \(\zeta < 1\) means it oscillates at \(\omega_n\sqrt{1-\zeta^2}\) while decaying like \(e^{-\zeta\omega_nt}\); \(\zeta = 1\) is critical damping; \(\zeta > 1\) means it creeps in without oscillating.

Section 7.8Worked examples

Worked examples

Find \(G\), its poles and zeros, and its DC gain for \(\ddot y + 5\dot y + 6y = 2\dot u - 4u\).

Solution

\(G(s) = \frac{2s - 4}{s^2 + 5s + 6} = \frac{2(s-2)}{(s+2)(s+3)}\). Zero at 2, poles at \(-2, -3\): stable. \(G(0) = -4/6 = -\tfrac23\). (A zero in the right half-plane does not affect stability.)

A current source drives \(R = 2\), \(L = 1\) and \(C = \tfrac14\) in parallel. Find the impedance \(Z(s)\) and its poles.

Solution $$Z(s) = \left(\frac12 + \frac1s + \frac s4\right)^{-1} = \frac{4s}{s^2 + 2s + 4}.$$

Poles: \(-1 \pm i\sqrt3\). \(Z(0) = 0\): at DC the inductor shorts everything.

For a unit step input, find \(y(\infty)\) (if it exists) for (a) \(G = \frac{s+4}{(s+1)(s^2+2s+2)}\), (b) \(G = \frac{s+4}{(s+1)(s^2 - 2s + 2)}\), (c) \(G = \frac{3}{s(s+2)}\).

Solution

(a) Poles \(-1, -1\pm i\): stable, so \(y(\infty) = G(0) = 4/2 = 2\).

(b) Poles \(1\pm i\) are unstable: no final value (growing oscillation).

(c) The pole at 0 is not in the open left half-plane, so the theorem does not apply. Indeed \(Y = \frac{3}{s^2(s+2)}\) contains \(\frac{3/2}{s^2}\), so \(y\) grows like \(\tfrac32t\).

\(2\ddot y + 4\dot y + 18y = u\) with \(u = 9\) N from rest. Find \(\omega_n\), \(\zeta\), the poles, the oscillation frequency and \(y(\infty)\).

Solution

\(\omega_n = \sqrt{18/2} = 3\), \(\zeta = \frac{4}{2\sqrt{36}} = \tfrac13\). The poles are roots of \(2s^2 + 4s + 18\): \(s = -1 \pm i\sqrt8\). It oscillates at \(\sqrt8 \approx 2.83\) rad/s \(= \omega_n\sqrt{1-\zeta^2}\), decays like \(e^{-t}\), and settles at \(y(\infty) = 9/18 = 0.5\) m.

Find the step response of \(G(s) = \frac{6}{(s+1)(s+3)}\) with \(u = 2\).

Solution

\(Y = \frac{12}{s(s+1)(s+3)} = \frac4s - \frac6{s+1} + \frac2{s+3}\), so \(y(t) = 4 - 6e^{-t} + 2e^{-3t}\). Check: \(y(0) = 0\) ✓ and \(y(\infty) = G(0)\cdot2 = 4\) ✓.
