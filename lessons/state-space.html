State Space

A transfer function describes a system from input to output. A state-space model describes what happens inside: a vector of states, such as positions and velocities or capacitor voltages and inductor currents, that evolves by a first-order matrix ODE. This lesson solves \(\dot x = Ax + Bu\) with the matrix exponential, links eigenvalues to poles and stability, computes \(G(s) = C(sI-A)^{-1}B + D\), and turns ODEs and mass–spring–damper systems into state-space form.

Section 8.1The state-space model

A linear, time-invariant state-space system is

$$\dot x = Ax + Bu,\qquad y = Cx + Du,$$

where \(x(t)\in\mathbb R^n\) is the state, \(u\) the input and \(y\) the output. \(A\) is \(n\times n\), \(B\) is \(n\times1\), \(C\) is \(1\times n\) and \(D\) is a scalar (for one input and one output). The state summarizes the past: knowing \(x(t_0)\) and the input after \(t_0\) determines everything after \(t_0\). MATLAB stores the system as ss(A,B,C,D), and Simulink builds it from integrators.

Section 8.2The matrix exponential

The scalar equation \(\dot x = ax\) has solution \(e^{at}x(0)\). The matrix version uses the matrix exponential

$$e^{At} = I + At + \frac{(At)^2}{2!} + \frac{(At)^3}{3!} + \cdots,\qquad \frac{d}{dt}e^{At} = Ae^{At},\qquad e^{A\cdot0} = I.$$

Transforming \(\dot x = Ax\) gives \(sX - x(0) = AX\), so \(X(s) = (sI - A)^{-1}x(0)\) and

$$e^{At} = \mathcal L^{-1}\big\{(sI - A)^{-1}\big\}.$$

With an input, the solution is the free response plus a convolution:

$$x(t) = e^{At}x(0) + \int_0^te^{A(t-\sigma)}Bu(\sigma)\,d\sigma.$$

Example: \(A = \begin{bmatrix}0 & 1\\ -2 & -3\end{bmatrix}\). Then \((sI - A)^{-1} = \frac{1}{s^2+3s+2}\begin{bmatrix}s+3 & 1\\ -2 & s\end{bmatrix}\), and inverting each entry by partial fractions gives

$$e^{At} = \begin{bmatrix}2e^{-t} - e^{-2t} & e^{-t} - e^{-2t}\\ -2e^{-t} + 2e^{-2t} & -e^{-t} + 2e^{-2t}\end{bmatrix}.$$

If \(A = P\Lambda P^{-1}\) is diagonalizable, then \(e^{At} = Pe^{\Lambda t}P^{-1}\). Every entry is a combination of \(e^{\lambda_kt}\), one for each eigenvalue. A rotation \(A = \begin{bmatrix}0&-\omega\\ \omega&0\end{bmatrix}\) gives \(e^{At} = \begin{bmatrix}\cos\omega t&-\sin\omega t\\ \sin\omega t&\cos\omega t\end{bmatrix}\), the rotation matrices of the notes' Section 5.2.

Section 8.3Eigenvalues, poles and stability

\((sI - A)^{-1} = \frac{\operatorname{adj}(sI - A)}{\det(sI - A)}\), so the only possible poles are the roots of the characteristic polynomial \(\det(sI - A)\): the eigenvalues of \(A\). For a \(2\times2\) matrix, \(\det(sI - A) = s^2 - (\operatorname{tr}A)s + \det A\). The system is stable (\(e^{At}\to0\) for every initial state) exactly when every eigenvalue satisfies \(\Re\lambda < 0\). For \(2\times2\) that is \(\operatorname{tr}A < 0\) and \(\det A > 0\).

Section 8.4The transfer function

With \(x(0) = 0\), transforming gives \(sX = AX + BU\), so \(X = (sI - A)^{-1}BU\) and \(Y = CX + DU\):

$$G(s) = C(sI - A)^{-1}B + D,\qquad g(t) = Ce^{At}B + D\delta(t).$$

\(D\) is the direct term: \(G(\infty) = D\), and \(G\) is strictly proper exactly when \(D = 0\). The DC gain is \(G(0) = D - CA^{-1}B\). Every pole of \(G\) is an eigenvalue of \(A\). (An eigenvalue can cancel against a zero and fail to appear as a pole, but it is still in \(e^{At}\).) In MATLAB: [num,den] = ss2tf(A,B,C,D), or tf(ss(A,B,C,D)).

Section 8.5Realizations: from an ODE to state space

Going the other way, a state-space model with \(C(sI-A)^{-1}B + D = G(s)\) is a realization of \(G\). For an ODE, choose the output and its derivatives as states. For \(\ddot y + a_1\dot y + a_0y = bu\), take \(x_1 = y\), \(x_2 = \dot y\):

$$\dot x = \begin{bmatrix}0 & 1\\ -a_0 & -a_1\end{bmatrix}x + \begin{bmatrix}0\\ b\end{bmatrix}u,\qquad y = \begin{bmatrix}1 & 0\end{bmatrix}x.$$

This companion form has \(\det(sI - A) = s^2 + a_1s + a_0\). In general, for \(G(s) = \frac{b_{n-1}s^{n-1} + \cdots + b_0}{s^n + a_{n-1}s^{n-1} + \cdots + a_0} + D\), the controllable canonical realization is

$$A = \begin{bmatrix}0&1&&\\&\ddots&\ddots&\\&&0&1\\-a_0&-a_1&\cdots&-a_{n-1}\end{bmatrix},\quad B = \begin{bmatrix}0\\ \vdots\\ 0\\ 1\end{bmatrix},\quad C = \begin{bmatrix}b_0&b_1&\cdots&b_{n-1}\end{bmatrix},\quad D.$$

The same idea works for any order. For \(y^{(n)} + a_{n-1}y^{(n-1)} + \cdots + a_1\dot y + a_0y = bu\), take \(x_1 = y, x_2 = \dot y, \dots, x_n = y^{(n-1)}\), so \(\dot x_j = x_{j+1}\) and \(\dot x_n = -a_0x_1 - \cdots - a_{n-1}x_n + bu\), with \(x(0) = [y(0), \dot y(0), \dots, y^{(n-1)}(0)]^T\). Any linear ODE can be put in state-space form. Different outputs only change \(C\) (and \(D\)): for \(m\ddot y + c\dot y + ky = u\) with \(x = (y, \dot y)\), position is \(C = [1\ 0]\), velocity is \(C = [0\ 1]\), and \(z = 3y - 2\dot y\) is \(C = [3\ {-2}]\), all with the same \(A = \begin{bmatrix}0&1\\-k/m&-c/m\end{bmatrix}\) and \(B = \begin{bmatrix}0\\1/m\end{bmatrix}\).

Section 8.6McMillan degree and minimal realizations

Which \(G\) can be realized? \((sI - A)^{-1} = M(s)/\Delta(s)\), where \(\Delta = \det(sI - A)\) has degree \(n\) and the adjugate \(M\) has entries of degree at most \(n - 1\). So \(C(sI-A)^{-1}B\) is strictly proper and \(G = \frac{c(s)}{\det(sI - A)} + D\) is proper. Conversely every proper rational \(G\) has a realization, for example the companion form above. \(G\) has a state-space realization if and only if it is proper, and its poles are contained in the eigenvalues of \(A\).

The McMillan degree of \(G = p/d\) is the degree of \(d\) after cancelling all common roots of \(p\) and \(d\): the number of poles, counted with multiplicity. A realization is minimal if no realization has a smaller state dimension, and

$$\{A\text{ on }\mathbb C^n, B, C, D\}\text{ is minimal}\iff n = \text{McMillan degree of }G\iff\text{eigenvalues of }A = \text{poles of }G.$$

Two realizations are similar if \(A_1 = TAT^{-1}\), \(B_1 = TB\), \(C_1 = CT^{-1}\), \(D_1 = D\) for an invertible \(T\) (a change of state variables \(\xi = Tx\)). Similar realizations have the same transfer function, because \(CT^{-1}(sI - TAT^{-1})^{-1}TB = C(sI - A)^{-1}B\). Moreover, all minimal realizations of the same \(G\) are similar. So realizations are not unique; MATLAB's tf2ss returns one, and minreal removes cancelling pole–zero pairs.

A pole–zero cancellation (from the notes). The notes' third-order system with \(C = [1\ \ 4\ \ 3]\) has \(A\) with eigenvalues \(\{-1\pm3i, -4\}\) (so \(A\) is stable) and transfer function

$$G(s) = \frac{s^2 + 6s + 8}{s^3 + 6s^2 + 18s + 40} = \frac{(s+2)(s+4)}{(s^2 + 2s + 10)(s+4)} = \frac{s+2}{s^2 + 2s + 10}.$$

The factor \(s + 4\) cancels (its residue is zero), so the McMillan degree is 2, the three-state model is not minimal, and the eigenvalue \(-4\) is not a pole of \(G\). A minimal (companion-form) realization is \(A_1 = \begin{bmatrix}0&1\\-10&-2\end{bmatrix}\), \(B_1 = \begin{bmatrix}0\\1\end{bmatrix}\), \(C_1 = [2\ \ 1]\). With \(u = 30\): \(G(0) = \tfrac15\), so \(y(\infty) = 6\), approached like \(e^{-t}\) while oscillating at 3 rad/s.

Section 8.7Mass–spring–damper systems

A system of masses, springs and dampers with position vector \(q\) obeys

$$M\ddot q + \Phi\dot q + Kq = bu,$$

with mass matrix \(M\), damping matrix \(\Phi\) and stiffness matrix \(K\), all symmetric and positive (semi)definite. With state \(x = \begin{bmatrix}q\\ \dot q\end{bmatrix}\),

$$\dot x = \begin{bmatrix}0 & I\\ -M^{-1}K & -M^{-1}\Phi\end{bmatrix}x + \begin{bmatrix}0\\ M^{-1}b\end{bmatrix}u.$$

When \(M > 0\), \(K > 0\) and \(\Phi > 0\) the system is stable. The energy \(\tfrac12\dot q^TM\dot q + \tfrac12q^TKq\) decreases at the rate \(\dot q^T\Phi\dot q\). With no damping (\(\Phi = 0\)), the eigenvalues lie on the imaginary axis and the masses oscillate at the natural frequencies \(\omega\), where \(\omega^2\) are the eigenvalues of \(M^{-1}K\). For one mass this is the familiar \(\begin{bmatrix}0&1\\-k/m&-c/m\end{bmatrix}\).

Section 8.8Worked examples

Worked examples

\(A = \begin{bmatrix}-1 & 2\\ 0 & -3\end{bmatrix}\), \(B = \begin{bmatrix}0\\1\end{bmatrix}\), \(C = \begin{bmatrix}1 & 1\end{bmatrix}\), \(D = 0\). Find \(G(s)\).

Solution

\(\det(sI - A) = (s+1)(s+3)\). \((sI-A)^{-1}B = \frac{1}{(s+1)(s+3)}\begin{bmatrix}s+3 & 2\\ 0 & s+1\end{bmatrix}\begin{bmatrix}0\\1\end{bmatrix} = \frac{1}{(s+1)(s+3)}\begin{bmatrix}2\\ s+1\end{bmatrix}\).

$$G(s) = \frac{2 + s + 1}{(s+1)(s+3)} = \frac{s+3}{(s+1)(s+3)} = \frac{1}{s+1}.$$

The eigenvalue \(-3\) cancels: it is not a pole of \(G\), but it still appears in \(e^{At}\).

Find \(e^{At}\) for \(A = \begin{bmatrix}-2 & 1\\ 0 & -2\end{bmatrix}\).

Solution

\((sI - A)^{-1} = \begin{bmatrix}\frac1{s+2} & \frac1{(s+2)^2}\\ 0 & \frac1{s+2}\end{bmatrix}\), so \(e^{At} = \begin{bmatrix}e^{-2t} & te^{-2t}\\ 0 & e^{-2t}\end{bmatrix}\). The repeated eigenvalue with only one eigenvector produces \(te^{-2t}\), just as a repeated pole does.

For \(A = \begin{bmatrix}0 & 1\\ -2 & -3\end{bmatrix}\) and \(x(0) = \begin{bmatrix}1\\ 0\end{bmatrix}\), find \(x(t)\).

Solution

\(x(t) = e^{At}x(0)\) is the first column of \(e^{At}\) (Section 8.2): \(x_1 = 2e^{-t} - e^{-2t}\), \(x_2 = -2e^{-t} + 2e^{-2t}\). Check \(\dot x_1 = x_2\) ✓ and \(x(0) = (1, 0)\) ✓.

Give a state-space realization of \(G(s) = \dfrac{3s + 1}{s^2 + 4s + 5}\).

Solution

Controllable canonical form: \(A = \begin{bmatrix}0 & 1\\ -5 & -4\end{bmatrix}\), \(B = \begin{bmatrix}0\\1\end{bmatrix}\), \(C = \begin{bmatrix}1 & 3\end{bmatrix}\), \(D = 0\). Check: \((sI - A)^{-1}B = \frac{1}{s^2+4s+5}\begin{bmatrix}1\\ s\end{bmatrix}\), so \(C(sI-A)^{-1}B = \frac{1 + 3s}{s^2+4s+5}\). ✓

Is \(\dot x = \begin{bmatrix}1 & 2\\ -3 & -4\end{bmatrix}x\) stable?

Solution

\(\operatorname{tr}A = -3 < 0\) and \(\det A = -4 + 6 = 2 > 0\), so yes. The eigenvalues are the roots of \(s^2 + 3s + 2\), namely \(-1\) and \(-2\). The positive entry \(a_{11} = 1\) does not matter; only the eigenvalues do.
