Complex Numbers

Every signal in this course is built from complex exponentials, so complex arithmetic has to be automatic. This lesson covers rectangular and polar form, Euler's formula, powers and roots, complex exponents and logarithms, and the phasor method for adding sinusoids. These are the skills Exam 1 tests directly in its first problem and uses in every other one.

Section 1.1Rectangular form and arithmetic

A complex number is \(z = x + iy\) with real part \(x = \Re z\), imaginary part \(y = \Im z\), and \(i^2 = -1\). (MATLAB and the lecture slides also write \(j\).) Add and subtract part by part; multiply by expanding and using \(i^2=-1\):

$$(x_1+iy_1)(x_2+iy_2) = (x_1x_2 - y_1y_2) + i(x_1y_2 + y_1x_2).$$

The conjugate is \(\bar z = x - iy\), the reflection across the real axis, and the modulus is \(|z| = \sqrt{x^2+y^2}\). They are linked by \(z\bar z = |z|^2\), which is the key to division: multiply top and bottom by the conjugate of the denominator.

$$\frac{z_1}{z_2} = \frac{z_1\bar z_2}{|z_2|^2}, \qquad \text{e.g.}\quad \frac{1+2i}{3-i} = \frac{(1+2i)(3+i)}{10} = \frac{1+7i}{10}.$$

Useful facts: \(\overline{z_1z_2} = \bar z_1\bar z_2\), \(\overline{z_1+z_2} = \bar z_1+\bar z_2\), \(\Re z = (z+\bar z)/2\), \(\Im z = (z-\bar z)/(2i)\), \(|z_1z_2| = |z_1||z_2|\), and the triangle inequality \(|z_1+z_2| \le |z_1|+|z_2|\). Also \(1/i = -i\) and the powers of \(i\) cycle with period 4: \(i, -1, -i, 1\).

Section 1.2Polar form and Euler's formula

Euler's formula \(e^{i\theta} = \cos\theta + i\sin\theta\) puts every nonzero complex number in polar form

$$z = re^{i\theta},\qquad r = |z|,\qquad \theta = \angle z,$$

where \(e^{i\theta}\) is the point at angle \(\theta\) on the unit circle. In polar form multiplication and division are easy: moduli multiply and angles add,

$$r_1e^{i\theta_1}\cdot r_2e^{i\theta_2} = r_1r_2\,e^{i(\theta_1+\theta_2)}, \qquad \frac{r_1e^{i\theta_1}}{r_2e^{i\theta_2}} = \frac{r_1}{r_2}e^{i(\theta_1-\theta_2)}.$$

So for a quotient of products such as \(\gamma = \dfrac{-i(3+2i)}{(1-4i)(-4-4i)}\), find \(|\gamma|\) as the product of the top moduli over the bottom ones, and \(\angle\gamma\) as the sum of top angles minus the bottom angles. Then wrap the angle back into \((-\pi, \pi]\).

The angle trap\(\angle z\) is not \(\tan^{-1}(y/x)\) when \(x < 0\). The arctangent only returns angles in \((-\pi/2, \pi/2)\), so for points in the left half-plane add or subtract \(\pi\): \(\angle(-1-i) = -3\pi/4\), not \(\pi/4\). MATLAB's angle(z) and atan2(y, x) do this correctly. Always sketch the point first.

Inverting Euler's formula gives the two identities used constantly in Fourier analysis:

$$\cos\theta = \frac{e^{i\theta} + e^{-i\theta}}{2},\qquad \sin\theta = \frac{e^{i\theta} - e^{-i\theta}}{2i}.$$

Section 1.3Powers: De Moivre's formula

Raising \(z = re^{i\theta}\) to an integer power multiplies its angle:

$$z^n = r^ne^{in\theta} = r^n(\cos n\theta + i\sin n\theta).$$

This turns \((1+i)^{10}\), which would take ten multiplications, into one line: \(1+i = \sqrt2e^{i\pi/4}\), so \((1+i)^{10} = 2^5e^{i10\pi/4} = 32e^{i\pi/2} = 32i\). The recipe is always the same: convert to polar, raise the modulus to the power, multiply the angle, reduce the angle modulo \(2\pi\), and convert back. For huge powers, leave the answer as \(r^ne^{i\theta}\).

Section 1.4Roots and roots of unity

The equation \(z^n = w\) with \(w = \rho e^{i\phi} \ne 0\) has exactly \(n\) solutions. Because \(e^{i\phi} = e^{i(\phi + 2\pi k)}\) for every integer \(k\),

$$z_k = \rho^{1/n}\,e^{i(\phi + 2\pi k)/n},\qquad k = 0, 1, \dots, n-1.$$

The roots all lie on the circle of radius \(\rho^{1/n}\) and are spaced \(2\pi/n\) apart: they are the vertices of a regular \(n\)-gon. For \(w = 1\) these are the roots of unity \(\lambda_k = e^{2\pi ik/n}\). Their sum is zero for \(n \ge 2\) (a geometric series, or the symmetry of the polygon). This fact is exactly why the DFT matrix of Lesson 4 is invertible with \(F^{-1} = F^*/\nu\).

Exams often ask for "the root with the smallest positive angle" or "all solutions of \(z^4 + 16 = 0\)". For the second: \(z^4 = -16 = 16e^{i\pi}\), so \(z = 2e^{i(\pi + 2\pi k)/4}\), giving \(\sqrt2(\pm1 \pm i)\).

Section 1.5Complex exponents, logarithms and trig functions

The exponential of \(z = x+iy\) is \(e^z = e^xe^{iy}\): the real part sets the size and the imaginary part sets the angle. Because \(e^{i2\pi k} = 1\), the logarithm is many-valued:

$$\ln z = \ln|z| + i(\angle z + 2\pi k),\qquad k \in \mathbb Z.$$

The principal value takes \(k=0\) and \(\angle z \in (-\pi,\pi]\). Complex powers are defined through the logarithm, \(a^b = e^{b\ln a}\). The classic example is real:

$$i^i = e^{i\ln i} = e^{i\cdot i(\pi/2 + 2\pi k)} = e^{-\pi/2 - 2\pi k}, \qquad \text{principal value } e^{-\pi/2} \approx 0.2079.$$

Similarly \(2^i = e^{i\ln 2} = \cos(\ln2) + i\sin(\ln 2)\), a point on the unit circle. Euler's identities define \(\cos\) and \(\sin\) for complex arguments; on the imaginary axis they become hyperbolic functions:

$$\cos(ib) = \frac{e^{-b}+e^{b}}{2} = \cosh b, \qquad \sin(ib) = \frac{e^{-b}-e^{b}}{2i} = i\sinh b.$$

So \(\cos z\) is unbounded in the complex plane, unlike on the real line. The same identities prove trigonometric formulas in a line, such as \(\cos^2\theta = \tfrac12 + \tfrac12\cos2\theta\) and \(\sin^3\theta = \tfrac34\sin\theta - \tfrac14\sin3\theta\), which Lesson 3 uses to read off Fourier coefficients.

One more tool from the notes is the geometric sum, \(\sum_{k=0}^{n-1} q^k = \dfrac{1-q^n}{1-q}\) for \(q \ne 1\). With \(q = i\) or \(q = e^{2\pi i/n}\) it collapses many exam sums.

Section 1.6Sinusoids and phasors

Any combination of a cosine and a sine at the same frequency is one shifted cosine. In the course's harmonic form,

$$\alpha\cos\omega t + \beta\sin\omega t = \gamma\cos(\omega t - \psi),\qquad \gamma = \sqrt{\alpha^2+\beta^2} = |\alpha + i\beta|,\quad \psi = \angle(\alpha + i\beta).$$

To see why, note that \(\Re\big[(\alpha + i\beta)e^{-i\omega t}\big] = \alpha\cos\omega t + \beta\sin\omega t\), and \((\alpha+i\beta) = \gamma e^{i\psi}\) gives \(\Re[\gamma e^{-i(\omega t - \psi)}] = \gamma\cos(\omega t-\psi)\). The complex number \(\alpha + i\beta\) is the phasor of the sinusoid. Sums of sinusoids at one frequency are sums of phasors, which you can add as vectors:

$$\gamma_1\cos(\omega t - \psi_1) + \gamma_2\cos(\omega t - \psi_2) = \gamma\cos(\omega t - \psi),\qquad \gamma e^{i\psi} = \gamma_1e^{i\psi_1} + \gamma_2e^{i\psi_2}.$$

This is the same \(\gamma_k, \psi_k\) that appears in the harmonic form of a Fourier series in Lesson 3. Use the angle rule from Section 1.2 for \(\psi\): \(-\cos t - \sin t = \sqrt2\cos(t + 3\pi/4)\), since \(\angle(-1-i) = -3\pi/4\).

Section 1.7Worked examples

These are written in the style of the exam problems. Try each one on paper before opening the solution.

Worked examples

Find \(|\gamma|\) and \(\angle\gamma \in (-\pi,\pi]\) for \(\displaystyle \gamma = \frac{2i(1+i)}{(1-i)(-\sqrt3 + i)}\).

Solution

Work factor by factor in polar form: \(2i = 2e^{i\pi/2}\), \(1+i = \sqrt2e^{i\pi/4}\), \(1-i = \sqrt2e^{-i\pi/4}\), and \(-\sqrt3+i = 2e^{i5\pi/6}\) (second quadrant, so the angle is \(\pi - \pi/6\)).

$$|\gamma| = \frac{2\cdot\sqrt2}{\sqrt2\cdot 2} = 1,\qquad \angle\gamma = \frac\pi2 + \frac\pi4 - \left(-\frac\pi4\right) - \frac{5\pi}6 = \frac{\pi}{6}.$$

Check by multiplying out: \(\gamma = e^{i\pi/6} = \tfrac{\sqrt3}{2} + \tfrac i2\).

Compute \((\sqrt3 - i)^{9}\) and \((1-i)^{7}\).

Solution

\(\sqrt3 - i = 2e^{-i\pi/6}\), so \((\sqrt3-i)^9 = 2^9e^{-i9\pi/6} = 512e^{-i3\pi/2} = 512e^{i\pi/2} = 512i\).

\(1 - i = \sqrt2e^{-i\pi/4}\), so \((1-i)^7 = 2^{7/2}e^{-i7\pi/4} = 8\sqrt2e^{i\pi/4} = 8\sqrt2\cdot\tfrac{1+i}{\sqrt2} = 8 + 8i\).

Find all solutions of \(z^3 + 8i = 0\), and the one with the smallest nonnegative angle.

Solution

\(z^3 = -8i = 8e^{-i\pi/2} = 8e^{i(-\pi/2 + 2\pi k)}\), so \(z_k = 2e^{i(-\pi/6 + 2\pi k/3)}\):

$$z_0 = 2e^{-i\pi/6} = \sqrt3 - i,\qquad z_1 = 2e^{i\pi/2} = 2i,\qquad z_2 = 2e^{i7\pi/6} = -\sqrt3 - i.$$

Measured in \([0,2\pi)\), the angles are \(11\pi/6\), \(\pi/2\) and \(7\pi/6\), so the smallest is \(z = 2i\). Check: \((2i)^3 = -8i\). ✓

Find all values of \(i^i\), the principal value of \(2^{i}\), and \(\cos(2i)\).

Solution

\(\ln i = i(\pi/2 + 2\pi k)\), so \(i^i = e^{i\ln i} = e^{-\pi/2 - 2\pi k}\), all real; the principal value is \(e^{-\pi/2} \approx 0.208\).

\(2^i = e^{i\ln2} = \cos(\ln 2) + i\sin(\ln 2) \approx 0.769 + 0.639i\), with modulus 1.

\(\cos(2i) = \dfrac{e^{i\cdot2i} + e^{-i\cdot2i}}{2} = \dfrac{e^{-2} + e^{2}}{2} = \cosh2 \approx 3.762\).

Write \(f(t) = -3\cos 2t + 3\sqrt3\sin 2t\) as \(\gamma\cos(2t - \psi)\).

Solution

The phasor is \(\alpha + i\beta = -3 + 3\sqrt3i\). Its modulus is \(\gamma = \sqrt{9 + 27} = 6\). It lies in the second quadrant, so \(\psi = \pi - \tan^{-1}(\sqrt3) = 2\pi/3\) (the bare arctangent would give the wrong \(-\pi/3\)).

$$f(t) = 6\cos\!\left(2t - \tfrac{2\pi}{3}\right).$$

Check at \(t=0\): \(6\cos(-2\pi/3) = -3\). ✓
