Lesson 2 · Exam 1

Inner Products & Orthogonal Expansions

A Fourier series is an expansion in an orthogonal basis, and the same geometry works for arrows in the plane, vectors in \(\mathbb C^n\) and functions in \(L^2(0,\tau)\). This lesson gives the tools: linear spaces, inner products and norms, Cauchy–Schwarz, orthogonality, and orthogonal expansions with Parseval's formula and the best-approximation property. Once these are in place, Lesson 3 needs only one new idea, which is the basis \(e^{-ik\omega_0t}\).

Section 2.1Linear spaces

A linear (vector) space is a set where you can add elements and multiply them by scalars (here complex numbers) with the usual rules. The three spaces of this course are:

  • \(\mathbb C^n\), column vectors of \(n\) complex numbers. Samples of a signal live here.
  • \(L^2(0,\tau)\), functions on \([0,\tau]\) with \(\int_0^\tau |f(t)|^2dt < \infty\), the finite-energy signals. Periodic signals live here, viewed over one period.
  • Trigonometric polynomials \(\sum_{k=-n}^{n} a_ke^{-ik\omega_0t}\), a finite-dimensional subspace of \(L^2(0,\tau)\) with dimension \(2n+1\). These are what the DFT works with.

A set \(\{\varphi_k\}\) is linearly independent if \(\sum c_k\varphi_k = 0\) forces every \(c_k = 0\), and it is a basis if in addition every element is some combination \(\sum c_k\varphi_k\). The number of basis elements is the dimension: \(n\) for \(\mathbb C^n\), infinite for \(L^2(0,\tau)\).

Section 2.2Inner products and norms

An inner product \((f,g)\) assigns a complex number to each pair of elements so that

$$(f,f) > 0 \text{ for } f\ne0,\qquad (g,f) = \overline{(f,g)},\qquad (c_1f_1 + c_2f_2, g) = c_1(f_1,g) + c_2(f_2,g).$$

It is linear in the first slot and conjugate-linear in the second: \((f, cg) = \bar c\,(f,g)\). On \(\mathbb C^n\) the standard inner product conjugates the second vector:

$$(f, g) = \sum_{k=1}^n f_k\overline{g_k} = g^*f.$$

The norm (length) is \(\|f\| = \sqrt{(f,f)}\) and the distance between \(f\) and \(g\) is \(\|f-g\|\). For \(f = [1+i,\;2]^T\), \(\|f\|^2 = |1+i|^2 + |2|^2 = 6\). Forgetting the conjugate is the most common mistake: \((1+i)(1+i) = 2i\) is not \(|1+i|^2\).

Section 2.3Cauchy–Schwarz, angles and orthogonality

The Cauchy–Schwarz inequality \(|(f,g)| \le \|f\|\,\|g\|\) holds in every inner product space, with equality only when one element is a multiple of the other. It lets us define the angle between real vectors by \(\cos\theta = (f,g)/(\|f\|\|g\|)\), and it implies the triangle inequality \(\|f+g\|\le\|f\|+\|g\|\).

Two elements are orthogonal, \(f\perp g\), when \((f,g) = 0\). For orthogonal elements the Pythagorean theorem holds: \(\|f+g\|^2 = \|f\|^2 + \|g\|^2\). The projection of \(f\) onto \(g\) is the multiple of \(g\) closest to \(f\):

$$P_gf = \frac{(f,g)}{\|g\|^2}\,g, \qquad f - P_gf \perp g.$$

Section 2.4Inner products of functions

On \(L^2(0,\tau)\) the course uses the normalized inner product

$$(f,g) = \frac1\tau\int_0^\tau f(t)\overline{g(t)}\,dt,\qquad \|f\|^2 = \frac1\tau\int_0^\tau |f(t)|^2\,dt.$$

The factor \(1/\tau\) makes \(\|f\|^2\) the average power of the signal and makes each \(e^{-ik\omega_0t}\) a unit vector. On a general interval \((a,b)\) the normalization is \(1/(b-a)\). Watch for it: an exam answer of \(4/3\) where \(2/3\) was expected usually means the factor was dropped.

Orthogonality of functions depends on the interval. \(\cos(\pi t/4)\) and \(\sin(\pi t/4)\) are orthogonal on \((0,4)\), where their product \(\tfrac12\sin(\pi t/2)\) runs through a full period and averages to zero. They are not orthogonal on \((0,2)\), which covers only the positive half of that period. The basic orthogonality relations, valid on any interval of length \(\tau = 2\pi/\omega_0\), are

$$\frac1\tau\int_0^\tau e^{-ik\omega_0t}\,\overline{e^{-in\omega_0t}}\,dt = \frac1\tau\int_0^\tau e^{-i(k-n)\omega_0t}\,dt = \begin{cases}1 & k=n\\ 0 & k\ne n.\end{cases}$$

So \(\{e^{-ik\omega_0t}\}_{k\in\mathbb Z}\) is orthonormal in \(L^2(0,\tau)\). The real set \(\{1, \cos k\omega_0t, \sin k\omega_0t\}\) is orthogonal but not orthonormal: \(\|\cos k\omega_0t\|^2 = \|\sin k\omega_0t\|^2 = \tfrac12\).

Section 2.5Orthogonal expansions and Parseval

If \(\{\varphi_k\}\) is an orthogonal basis, every \(f\) expands as \(f = \sum_k a_k\varphi_k\). Taking the inner product of both sides with \(\varphi_n\) kills every term but one, so the coefficients come straight from inner products:

$$a_k = \frac{(f,\varphi_k)}{\|\varphi_k\|^2}\qquad\big(a_k = (f,\varphi_k)\text{ if the basis is orthonormal}\big).$$

No linear system has to be solved. Applying Pythagoras to all the terms gives Parseval's formula:

$$\|f\|^2 = \sum_k |a_k|^2\,\|\varphi_k\|^2,\qquad (f,g) = \sum_k a_k\overline{b_k}\,\|\varphi_k\|^2.$$

For the Fourier basis this reads \(\frac1\tau\int_0^\tau|f|^2dt = \sum_k |a_k|^2\): the power of a signal equals the sum of the powers in its harmonics.

Section 2.6Best approximation

Suppose only the first \(N\) basis elements are kept. Which coefficients \(c_k\) make \(\|f - \sum_{k\le N} c_k\varphi_k\|\) smallest? The answer is the same \(a_k\) as in the full expansion. The truncated sum is the orthogonal projection of \(f\) onto the span of \(\varphi_1,\dots,\varphi_N\), the error is orthogonal to every \(\varphi_k\) kept, and its size follows from Parseval:

$$\Big\|f - \sum_{k\le N}a_k\varphi_k\Big\|^2 = \|f\|^2 - \sum_{k\le N}|a_k|^2\|\varphi_k\|^2 = \sum_{k>N}|a_k|^2\|\varphi_k\|^2.$$

This is the formula behind the "truncation error" problems in Lesson 3. It also explains why adding a term never makes the fit worse and never changes the coefficients already found, which is the great advantage of orthogonal bases.

Section 2.7Worked examples

Worked examples

For \(f = [1+i,\; 2,\; -i]^T\) and \(g = [i,\; 1-i,\; 3]^T\), compute \((f,g)\), \((g,f)\), \(\|f\|\) and \(\|g\|\), and check Cauchy–Schwarz.

Solution $$(f,g) = (1+i)\bar{i} + 2\,\overline{(1-i)} + (-i)\cdot 3 = (1+i)(-i) + 2(1+i) - 3i = (1 - i) + (2 + 2i) - 3i = 3 - 2i.$$

\((g,f) = \overline{(f,g)} = 3 + 2i\). \(\|f\|^2 = 2 + 4 + 1 = 7\) and \(\|g\|^2 = 1 + 2 + 9 = 12\). Then \(|(f,g)| = \sqrt{13} \approx 3.61 \le \sqrt{84} \approx 9.17\). ✓

Are \(\cos(\pi t/4)\) and \(\sin(\pi t/4)\) orthogonal in \(L^2(0,2)\)? In \(L^2(0,4)\)?

Solution

Use \(\cos x\sin x = \tfrac12\sin 2x\):

$$\frac1L\int_0^L \cos\tfrac{\pi t}4\sin\tfrac{\pi t}4\,dt = \frac1{2L}\int_0^L\sin\tfrac{\pi t}{2}\,dt = \frac{1}{2L}\cdot\frac2\pi\Big(1 - \cos\tfrac{\pi L}{2}\Big).$$

For \(L = 2\): \(\frac14\cdot\frac2\pi\cdot 2 = \frac1\pi \ne 0\), not orthogonal. For \(L = 4\): \(1 - \cos2\pi = 0\), orthogonal. Interactive 2 shows both.

Find the constant \(c\) so that \(g(t) = t - c\) is orthogonal to \(f(t) = t + 1\) in \(L^2(0,1)\). Then find \(\|f\|^2\).

Solution $$0 = \int_0^1 (t+1)(t-c)\,dt = \int_0^1 \big(t^2 + (1-c)t - c\big)dt = \frac13 + \frac{1-c}{2} - c = \frac56 - \frac{3c}2 \;\Rightarrow\; c = \frac59.$$

The normalization does not matter for orthogonality. \(\|f\|^2 = \int_0^1 (t+1)^2dt = \frac{(2)^3 - 1}{3} = \frac73\).

The Walsh vectors \(\psi_1 = [1,1,1,1]\), \(\psi_2 = [1,-1,1,-1]\), \(\psi_3 = [1,1,-1,-1]\), \(\psi_4 = [1,-1,-1,1]\) are an orthogonal basis of \(\mathbb C^4\). Expand \(f = [4, 2, 0, -2]\) and find the error of the best approximation using only \(\psi_1, \psi_2\).

Solution

Each \(\|\psi_k\|^2 = 4\). The coefficients are \(a_k = (f,\psi_k)/4\):

$$a_1 = \tfrac{4+2+0-2}{4} = 1,\quad a_2 = \tfrac{4-2+0+2}{4} = 1,\quad a_3 = \tfrac{4+2-0+2}{4} = 2,\quad a_4 = \tfrac{4-2-0-2}{4} = 0.$$

So \(f = \psi_1 + \psi_2 + 2\psi_3\). Parseval: \(\|f\|^2 = 24 = 4(1 + 1 + 4 + 0)\). ✓ The error with two terms is \(\|f\|^2 - 4(1+1) = 16 = |a_3|^2\|\psi_3\|^2\), so the distance is 4. Interactive 3 starts at this example.

Find the average power \(\|f\|^2\) of \(f(t) = 2 + 3\cos t - 4\sin 2t\) on \((0,2\pi)\) without integrating.

Solution

\(\{1, \cos t, \sin 2t\}\) are orthogonal with \(\|1\|^2 = 1\) and \(\|\cos t\|^2 = \|\sin 2t\|^2 = \tfrac12\). By Parseval,

$$\|f\|^2 = 2^2\cdot 1 + 3^2\cdot\tfrac12 + 4^2\cdot\tfrac12 = 4 + 4.5 + 8 = 16.5.$$

SummaryKey equations

Inner products

$$(f,g) = \sum f_k\overline{g_k},\qquad (f,g) = \frac1\tau\int_0^\tau f\bar g\,dt$$ $$(g,f) = \overline{(f,g)},\quad (f,cg) = \bar c(f,g)$$

Geometry

$$|(f,g)| \le \|f\|\|g\|,\qquad f\perp g \iff (f,g) = 0$$ $$P_gf = \frac{(f,g)}{\|g\|^2}g$$

Expansion

$$f = \sum a_k\varphi_k,\qquad a_k = \frac{(f,\varphi_k)}{\|\varphi_k\|^2}$$ $$\|f\|^2 = \sum|a_k|^2\|\varphi_k\|^2$$

Best approximation

$$\Big\|f - \sum_{k\le N}a_k\varphi_k\Big\|^2 = \sum_{k>N}|a_k|^2\|\varphi_k\|^2$$
