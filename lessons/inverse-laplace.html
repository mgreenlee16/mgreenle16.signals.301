Partial Fractions & Differential Equations

Transforming a problem is half the job; getting back to the time domain is the other half. For rational transforms, which cover every linear ODE with constant coefficients, the inverse comes from a partial fraction expansion. This lesson covers poles and zeros, the cover-up method for distinct real poles, complex poles and Lemma 1 of the notes, repeated poles, the direct term, MATLAB's residue, and solving ODEs with initial conditions.

Section 6.1Rational functions, poles and zeros

\(G(s) = n(s)/d(s)\) with polynomials \(n\) and \(d\) (no common roots) is a rational function. Its zeros are the roots of \(n\), and its poles are the roots of \(d\), where \(|G| = \infty\). For example

$$G(s) = \frac{(s-6)(s^2 - 2s + 2)}{(s+2)(s+4)(s^2+2s+5)}$$

has zeros \(\{6,\ 1\pm i\}\) and poles \(\{-2,\ -4,\ -1\pm2i\}\). \(G\) is proper if \(\deg n \le \deg d\) and strictly proper if \(\deg n < \deg d\). Real-coefficient polynomials have complex roots in conjugate pairs.

Section 6.2Distinct poles: the cover-up method

If \(G\) is strictly proper with distinct poles \(\lambda_1,\dots,\lambda_\nu\), it splits into simple fractions, each the transform of an exponential:

$$G(s) = \sum_{k=1}^{\nu}\frac{a_k}{s-\lambda_k},\qquad a_j = \big[G(s)(s-\lambda_j)\big]_{s=\lambda_j},\qquad g(t) = \sum_{k=1}^\nu a_ke^{\lambda_kt}.$$

Multiplying by \(s - \lambda_j\) "covers up" that factor of the denominator; evaluating at \(\lambda_j\) kills every other term. For \(G(s) = \frac{6(s+3)}{(s+1)(s+2)(s+4)}\):

$$a_1 = \left.\frac{6(s+3)}{(s+2)(s+4)}\right|_{s=-1} = 4,\quad a_2 = \left.\frac{6(s+3)}{(s+1)(s+4)}\right|_{s=-2} = -3,\quad a_3 = \left.\frac{6(s+3)}{(s+1)(s+2)}\right|_{s=-4} = -1,$$

so \(g(t) = 4e^{-t} - 3e^{-2t} - e^{-4t}\). The numbers \(a_k\) are the residues. In MATLAB, [r,p,k] = residue(num,den) returns them (r), the poles (p) and any direct term (k), with polynomials entered as coefficient vectors, highest power first, and products built with conv.

Section 6.3Complex poles

Cover-up works unchanged at complex poles, and the residues at conjugate poles are conjugates. The notes' Lemma 1 turns each conjugate pair into real functions:

$$\frac{\gamma}{s - a - i\omega} + \frac{\bar\gamma}{s - a + i\omega}\;\longrightarrow\; 2\Re(\gamma)\,e^{at}\cos\omega t - 2\Im(\gamma)\,e^{at}\sin\omega t.$$

Example: \(G(s) = \frac{20}{s(s^2+2s+5)}\) has poles \(0, -1\pm2i\). Cover-up gives \(a_1 = 20/5 = 4\) and \(\gamma = \left.\frac{20}{s(s+1+2i)}\right|_{s=-1+2i} = \frac{20}{(-1+2i)(4i)} = -2 + i\). So

$$g(t) = 4 + 2(-2)e^{-t}\cos2t - 2(1)e^{-t}\sin2t = 4 - 4e^{-t}\cos2t - 2e^{-t}\sin2t.$$

An alternative avoids complex arithmetic: complete the square and match \(\frac{B(s-a) + C\omega}{(s-a)^2+\omega^2} \to e^{at}(B\cos\omega t + C\sin\omega t)\). Either way, the real part \(a\) of the pole sets the decay rate and \(\omega\) sets the frequency.

Section 6.4Repeated poles

A pole \(\lambda\) of multiplicity \(m\) contributes \(m\) terms, \(\frac{c_m}{(s-\lambda)^m} + \dots + \frac{c_1}{s-\lambda}\), which invert to \(c_k\frac{t^{k-1}}{(k-1)!}e^{\lambda t}\). The top coefficient comes from cover-up with the whole power, \(c_m = [(s-\lambda)^mG(s)]_{s=\lambda}\). For the rest, either

  • use derivatives: \(c_{m-j} = \frac1{j!}\frac{d^j}{ds^j}\big[(s-\lambda)^mG(s)\big]_{s=\lambda}\); or
  • do as the notes do: subtract the term just found, simplify (the factor \(s-\lambda\) cancels), and cover up again.

For \(G(s) = \frac{1}{s(s+1)^3}\): \([sG]_{0} = 1\), \([(s+1)^3G]_{-1} = -1\), then \(-1\) and \(-1\) for the lower powers, so \(g(t) = 1 - \tfrac{t^2}{2}e^{-t} - te^{-t} - e^{-t}\).

Pole locations and the type of time function

Every term of \(g = \mathcal L^{-1}G\) is set by a pole (or a pair of poles). You can name the form of \(g\) just by looking at the s-plane:

Pole(s)Term in g(t)Behavior
real \(\lambda = -a < 0\)\(Ce^{-at}\)decays; time constant \(1/a\)
\(\lambda = 0\)\(C\) (a step)constant
real \(\lambda = a > 0\)\(Ce^{at}\)grows: unstable
pair \(\sigma \pm i\omega\), \(\sigma < 0\)\(e^{\sigma t}(B\cos\omega t + C\sin\omega t)\)decaying oscillation at \(\omega\) rad/s
pair \(\pm i\omega\)\(B\cos\omega t + C\sin\omega t\)sustained oscillation
pair \(\sigma \pm i\omega\), \(\sigma > 0\)\(e^{\sigma t}(B\cos\omega t + C\sin\omega t)\)growing oscillation: unstable
repeated \(\lambda\), multiplicity \(m\)\(e^{\lambda t}, te^{\lambda t}, \dots, t^{m-1}e^{\lambda t}\)a double pole at 0 gives a ramp \(C_1 + C_2t\)
\(\deg n = \deg d\)\(k\,\delta(t)\)direct term

The real part sets growth or decay and the imaginary part sets the frequency. The slowest-decaying (rightmost) poles dominate the response for large \(t\).

Section 6.5Proper functions: the direct term

If \(\deg n = \deg d\), first pull out the constant \(k = G(\infty)\), the ratio of the leading coefficients (or divide the polynomials). The remainder is strictly proper. The constant transforms back to an impulse, \(k\delta(t)\):

$$\frac{2s^2+3s+4}{s^2+3s+2} = 2 + \frac{3}{s+1} - \frac{6}{s+2} \;\longrightarrow\; g(t) = 2\delta(t) + 3e^{-t} - 6e^{-2t}.$$

Section 6.6Solving differential equations

The recipe: (1) transform both sides, using the derivative rule so the initial conditions enter; (2) solve the algebraic equation for \(Y(s)\); (3) expand in partial fractions; (4) invert term by term. For

$$\ddot y + 3\dot y + 2y = 2,\qquad y(0) = 2,\quad \dot y(0) = -10,$$

step 1 gives \(s^2Y - 2s + 10 + 3(sY - 2) + 2Y = 2/s\). So \(Y(s) = \frac{2s^2 - 4s + 2}{s(s+1)(s+2)}\), and cover-up gives

$$Y(s) = \frac1s - \frac{8}{s+1} + \frac{9}{s+2},\qquad y(t) = 1 - 8e^{-t} + 9e^{-2t}.$$

Check: \(y(0) = 2\) ✓, \(\dot y(0) = 8 - 18 = -10\) ✓, and \(y(\infty) = 1\) matches the steady state \(2y = 2\) ✓. The roots of the characteristic polynomial \(s^2 + 3s + 2\) are the poles that set the shape of the transient. Interactive 2 shows how they move as the coefficients change.

Section 6.7Worked examples

Worked examples

Invert \(G(s) = \dfrac{s^2 + 4}{s(s+1)(s-2)}\).

Solution

\(a_1 = [sG]_0 = \frac{4}{(1)(-2)} = -2\); \(a_2 = [(s+1)G]_{-1} = \frac{5}{(-1)(-3)} = \frac53\); \(a_3 = [(s-2)G]_{2} = \frac{8}{(2)(3)} = \frac43\). Check: \(a_1 + a_2 + a_3 = 1\), the ratio of the leading coefficients. ✓

$$g(t) = -2 + \tfrac53e^{-t} + \tfrac43e^{2t}.$$

Invert \(G(s) = \dfrac{4s^2 - 8s + 8}{s^2 + 4s + 20}\).

Solution

Same degree, so \(k = 4\). The poles are \(-2 \pm 4i\). Cover-up at \(-2 + 4i\): \(\gamma = \left.\frac{4s^2 - 8s + 8}{s + 2 + 4i}\right|_{s=-2+4i} = \frac{-24 - 96i}{8i} = -12 + 3i\). By Lemma 1:

$$g(t) = 4\delta(t) - 24e^{-2t}\cos4t - 6e^{-2t}\sin4t.$$

(Numerator at \(-2+4i\): \(4(-12 - 16i) - 8(-2 + 4i) + 8 = -24 - 96i\).)

Invert \(G(s) = \dfrac{s + 3}{(s+1)^2(s+2)}\).

Solution

\(d = [(s+2)G]_{-2} = \frac{1}{1} = 1\). \(h(s) = (s+1)^2G = \frac{s+3}{s+2}\): \(c_2 = h(-1) = 2\), \(c_1 = h'(-1) = \frac{(s+2) - (s+3)}{(s+2)^2}\big|_{-1} = -1\).

$$g(t) = 2te^{-t} - e^{-t} + e^{-2t}.$$

Check \(g(0) = 0\) (strictly proper with relative degree 2 means \(g(0) = 0\)). ✓

Find the impulse response of \(G(s) = \dfrac{s + 5}{s + 2}\).

Solution

\(G = 1 + \frac{3}{s+2}\), so \(g(t) = \delta(t) + 3e^{-2t}\). The \(\delta\) appears because the numerator and denominator have the same degree: part of the input passes straight through.

Solve \(\ddot y + 2\dot y + 5y = 0\), \(y(0) = 1\), \(\dot y(0) = 1\).

Solution

\(s^2Y - s - 1 + 2(sY - 1) + 5Y = 0\), so \(Y = \frac{s + 3}{s^2 + 2s + 5} = \frac{(s+1) + 2}{(s+1)^2 + 4}\). Matching the damped-sinusoid pairs:

$$y(t) = e^{-t}\cos2t + e^{-t}\sin2t.$$

Check \(\dot y(0) = -1 + 2 = 1\). ✓
